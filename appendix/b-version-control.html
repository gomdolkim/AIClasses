구글 문서의 '변경 기록'과 같아요

구글 문서의 파일 → 버전 기록을 열면 "10월 3일 오후 2시, 한봄이 수정" 같은 기록이 쭉 보이죠. 버전 관리는 이걸 내가 원하는 순간에, 메모를 붙여서 저장하는 방법입니다.
저장소 (Repository)
기록이 함께 보관되는 프로젝트 폴더. 홈페이지 하나 = 저장소 하나
커밋 (Commit)
"지금 상태를 저장 + 메모" 한 번. 게임의 세이브 포인트
푸시 (Push)
내 컴퓨터에 쌓인 커밋을 인터넷(GitHub)으로 올려 보내기

Git = 기록을 남기는 도구, GitHub = 그 기록을 인터넷에 보관하는 서비스. 카메라와 사진 클라우드 관계예요.

브랜치·머지·풀 리퀘스트 같은 단어는 일부러 뺌. 질문이 나오면 "평행 세이브 슬롯 같은 것, 혼자 쓰는 작은 가게 사이트에선 몰라도 된다"로 정리.

방법 1 · GitHub 웹사이트에서

  1. 부록 A 저장소 → index.html 클릭
  2. 오른쪽 위 연필(✏️ Edit) 아이콘 → 글자 수정
  3. Commit changes… → 메모 입력 → Commit changes
  4. 저장소 첫 화면의 Commits(시계 아이콘) → 기록 목록 확인
  5. 예전 커밋을 눌러 무엇이 바뀌었는지 보기 (빨강 = 지움, 초록 = 추가)

방법 2 · GitHub Desktop 프로그램

  1. desktop.github.com에서 내려받아 설치 → GitHub 계정으로 로그인
  2. File → Clone repository → bomnal-flower 선택 → 내 컴퓨터로 복사
  3. 평소처럼 폴더 안 파일을 고치고 저장
  4. 왼쪽 아래 메모 칸에 요약 입력 → Commit to main
  5. 위쪽 Push origin 클릭 → GitHub로 올라감

방법 3 · Claude Code에게 말로 맡기기

Claude Code(부록 C)는 파일을 고친 뒤 커밋 메모까지 대신 써서 저장해 줍니다.

지금까지 바꾼 내용을 확인하고, 알아보기 쉬운 한국어 메모로 커밋해 줘.
GitHub에 푸시해 줘.
최근 커밋 5개를 쉬운 말로 요약해 줘.
Claude Code는 실제 명령을 실행하기 전에 허락을 물어봅니다. 무엇을 하려는지 읽어 보고 승인하세요.
"되돌려 줘", "강제로 올려 줘"처럼 기록을 지우는 요청은 신중히. 먼저 "어떤 일이 생기는지 설명해 줘"라고 물어보세요.
Claude Code에서는 /rewind(되감기)로 대화와 코드를 이전 시점으로 돌릴 수도 있음(공식 문서 기준). 하지만 이미 푸시한 기록은 GitHub에 남아 있으니 안심해도 된다고 설명.

Claude Code"어제 오후 커밋 상태로 index.html만 되돌려 줘. 먼저 무엇이 바뀌는지 보여 줘."
되돌리기도 새 커밋으로 남기 때문에, 되돌린 것을 다시 되돌릴 수도 있어요. 기록은 지워지지 않습니다.
Revert는 '취소 커밋'을 새로 만드는 안전한 방식. reset 같은 기록 삭제 방식은 초보자에게 권하지 않음.

⚠️ 절대 올리면 안 되는 것

한 번 커밋해서 올린 파일은 지워도 기록에 남습니다. 공개 저장소라면 전 세계에 노출됩니다. API 키가 올라갔다면 즉시 해당 서비스에서 키를 폐기하고 새로 발급하세요.
  • API 키·비밀번호 (ANTHROPIC_API_KEY, LINE 채널 시크릿 등)
  • Slack Webhook 주소
  • 고객 명단·주문 장부
  • .env 파일

🛡️ .gitignore

"이 파일은 기록하지 마"라는 제외 목록 파일. Claude Code에게 "비밀값 파일이 올라가지 않게 .gitignore를 설정해 줘"라고 부탁하세요.

14회차 봇 서버의 비밀값은 코드에 넣지 않고 `npx wrangler secret put 이름`으로 Cloudflare에 따로 저장함 — 이 장과 연결. 체크 항목을 눌러 보게 하기.
