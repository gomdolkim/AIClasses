스킬이란? — 책장에 꽂힌 업무 매뉴얼

비서 책상 옆 책장에 매뉴얼이 여러 권 꽂혀 있다고 해 볼게요. 비서는 평소엔 책등의 제목만 훑어봅니다. "공지문 써 줘"라는 부탁을 받으면 그제야 「공지문 매뉴얼」을 꺼내 펼치고, 필요하면 뒤쪽 부록(가격표)까지 찾아봅니다.

SKILL.md
스킬 폴더 안의 매뉴얼 본문 파일. 맨 위에 이름(name)과 설명(description)을 적고, 그 아래에 일하는 방법을 씁니다

그래서 스킬을 여러 개 설치해도 대화가 무거워지지 않습니다. 책등만 늘어날 뿐이니까요.

공식 문서의 'progressive disclosure(단계별 공개)'를 책장 비유로 바꾼 것. 용어는 말하지 않아도 됨. 핵심: "설명(description)이 책등 제목 역할 → 설명을 잘 써야 Claude가 꺼내 본다."

claude.ai에서 스킬 켜기

👤 개인 (Free · Pro · Max)

  1. Settings(설정) → Capabilities(기능)
  2. Code execution and file creation 켜기
  3. Customize(사용자 지정) → Skills(스킬)에서 목록 확인

👥 팀 (Team · Enterprise)

  1. 관리자: Organization settings(조직 설정)에서 코드 실행과 Skills 허용
  2. 구성원: Customize → Skills에서 켜고 끄기
  3. 조직이 배포한 스킬은 팀 표시와 함께 목록에 나타남
기본 제공 스킬: Excel · Word · PowerPoint · PDF 만들기. 따로 부를 필요 없이 "엑셀로 만들어 줘"라고 하면 알아서 씁니다.

2026-10 도움말 기준: 스킬은 Free·Pro·Max·Team·Enterprise 모두 지원, 코드 실행 기능이 켜져 있어야 함. 일부 문서는 아직 예전 경로(Settings → Features)를 적고 있으니 수업 전 실제 화면 확인.

도움말끼리 표현이 엇갈림(Customize > Skills / Settings > Capabilities / Settings > Features). 화면에서 "Skills"를 찾으면 됨. Team 메뉴 이름은 도움말에 "Organization settings > Skills" 또는 "Plugins & skills"로 나옴 — 수업 전 확인.

폴더 이름은 SKILL.md의 name과 같게 맞추세요. 예제: examples/skills/README.md

zip 구조 오류가 업로드 실패의 대부분. "폴더를 오른쪽 클릭해서 압축"만 기억시키면 됨. Mac Finder 압축은 폴더째 묶임. 스킬을 고치면 zip을 다시 만들어 올리고, 이전 것은 삭제.

실습 · 대화하며 내 스킬 만들기 (skill-creator)

  1. Customize → Skills에서 Anthropic 예시 스킬 skill-creator가 켜져 있는지 확인
  2. 새 채팅에 오른쪽처럼 형식·말투·좋았던 예시를 한 번에 설명
  3. Claude의 질문에 답하면 SKILL.md가 완성됨
  4. 화면의 저장(스킬에 추가) 버튼을 누르거나, 파일을 받아 zip으로 묶어 업로드
  5. 새 채팅에서 평소처럼 부탁해 시험 → 스킬을 읽는 표시 확인
스킬을 하나 만들고 싶어. 이름은 bomnal-order-confirm. 할 일: 손님 주문을 받으면 '주문 확인 문자'를 써 주는 것. 형식: 4줄 이내 — 인사 / 상품·가격 / 받는 날짜·시간 / 문의처. 말투: 따뜻한 존댓말, 이모지 1개. 규칙: 가격은 가격표대로, 배송비 규칙(오후 3시 마감, 마포·서대문 무료) 반영. 손님 전화번호는 문자에 넣지 않기. 좋았던 예시: "안녕하세요, 봄날의 꽃이에요 🌷 / 꽃다발 M 55,000원 주문 확인했어요 / 5월 8일(목) 오후 2시에 받아 보실 수 있어요 / 궁금한 점은 인스타 @bomnal_flower 로 연락 주세요" 나한테 부족한 정보를 먼저 물어봐 줘.

저장 버튼 이름·위치는 화면마다 다를 수 있습니다(2026-10, 수업 전 확인). 버튼이 없으면 "SKILL.md 파일로 만들어 줘" → 내려받아 폴더에 넣고 zip으로 묶으세요.

공식 튜토리얼 요령: 여러 번 설명했던 일을 고르고, 형식·말투·실제 예시를 한 메시지에 담아 설명 → 새 대화에서 시험 → Claude 생각 표시에 스킬 이름을 읽는 흔적이 있는지 확인. skill-creator가 목록에 없어도 "스킬을 만들어 줘"라고 하면 대부분 진행됨. 안 되면 강사가 예제 SKILL.md를 틀로 주고 내용만 바꾸게 하기.

# 주문 확인 문자 매뉴얼

## 순서
1. 인사 (봄날의 꽃이에요 🌷)
2. 상품명과 가격 — references/price.md 확인
3. 받는 날짜·시간
4. 문의처: 인스타 @bomnal_flower

## 하지 말 것
- 가격표에 없는 금액 지어내기
- 손님 전화번호 적기

## 예시
안녕하세요, 봄날의 꽃이에요 🌷 …

① 머리말 (--- 사이)

name: 영어 소문자·숫자·하이픈, 64자 이내. "claude"·"anthropic" 단어 금지
description: 무엇을 + 언제. 짧게(도움말 기준 200자 이내)

② 본문

순서, 규칙, 하지 말 것, 예시. 신입에게 주는 매뉴얼처럼

③ 부록 파일 (선택)

가격표 같은 긴 자료는 references/에 따로. 본문에서 "확인하라"고 가리키기

공식 규칙: name은 소문자·숫자·하이픈 64자, 예약어(anthropic, claude) 불가. description은 API 문서 기준 1,024자까지지만 claude.ai 도움말은 200자 이내라고 적고 있음 → 짧게 쓰는 게 안전. 본문은 짧을수록 좋음(공식 권장: 본문 5천 토큰 미만, 대략 A4 몇 쪽). 길어지면 references로 분리.

좋은 스킬을 쓰는 6가지 요령

1. 설명에 '언제'

"공지, 안내문, 휴무 글을 요청받으면 사용"처럼 손님·직원이 실제 쓰는 말을 넣기

2. 한 스킬 = 한 업무

공지문, 주간 보고, 견적서는 각각 따로

3. 순서를 번호로

"1. 확인 → 2. 작성 → 3. 점검" 단계로

4. 좋은 예시 1개

실제로 만족했던 결과물을 붙여 넣기

5. 모르면 묻게

"자료에 없으면 [확인 필요]로 표시" 규칙

6. 고치며 키우기

이상한 결과가 나오면 그 경우를 '하지 말 것'에 추가

1번이 가장 중요: description이 책등 제목. 너무 막연하면("글쓰기 도우미") 엉뚱할 때 불리거나, 안 불림. 5번은 2회차 할루시네이션 대비와 같은 원리.

Claude Code에서 스킬 쓰기

Claude Code(부록 C)에서는 zip 없이 폴더를 넣기만 하면 됩니다.

위치범위
~/.claude/skills/스킬이름/SKILL.md내 컴퓨터의 모든 작업
.claude/skills/스킬이름/SKILL.md그 프로젝트 폴더에서만 (Git으로 팀 공유)
cp -r bomnal-notice-writer ~/.claude/skills/
  • /bomnal-notice-writer 추석 휴무 — 이름으로 직접 부르기
  • "공지문 써줘" — 설명을 보고 알아서 꺼내 씀
  • /skills — 설치된 스킬 목록 보기
공식 문서(code.claude.com/docs/en/skills): 개인 ~/.claude/skills, 프로젝트 .claude/skills, 플러그인 안의 skills. 같은 이름이면 개인이 프로젝트보다 우선. 부르기만 하고 Claude가 알아서 쓰지 않게 하려면 머리말에 disable-model-invocation: true — 초보자에겐 소개만. 참고: Excel·Word 등 기본 문서 스킬은 Claude Code에는 기본 포함이 아님(아래 플러그인으로 설치 가능).

플러그인 마켓플레이스로 스킬 묶음 설치

플러그인은 매뉴얼 전집 세트, 마켓플레이스는 그 전집을 파는 서점이에요. 서점을 한 번 등록하면 전집을 골라 설치할 수 있습니다.
# 1) Anthropic 공식 스킬 서점 등록
/plugin marketplace add anthropics/skills

# 2) 문서(Excel·Word·PowerPoint·PDF) 스킬 묶음 설치
/plugin install document-skills@anthropic-agent-skills

# 3) 설치된 플러그인 확인
/plugin list

Claude Code 입력창에 한 줄씩 입력합니다. 플러그인 스킬은 /플러그인이름:스킬이름으로 부를 수 있어요.

명령은 github.com/anthropics/skills README 기준(2026-10). 문서 스킬(docx·pdf·pptx·xlsx)은 오픈소스가 아니라 '소스 공개' 라이선스. 마켓플레이스도 아무거나 등록하지 말 것 → 다음 장 보안.

보안 주의 — 스킬은 '프로그램 설치'와 같아요

스킬에는 Claude가 그대로 따르는 지시문과 실제로 실행되는 코드가 들어갈 수 있습니다. 나쁜 스킬은 파일을 몰래 보내거나 엉뚱한 일을 시킬 수 있어요. 출처를 모르는 스킬은 설치하지 마세요.
  • 직접 만들었거나 Anthropic 등 믿을 수 있는 곳의 스킬만 설치한다
  • 남이 준 zip은 풀어서 SKILL.md와 모든 파일을 먼저 읽어 본다
  • "이 주소로 보내라", "이 사이트에서 받아 와라" 같은 문장이 있으면 설치하지 않는다
  • 스킬 안에 비밀번호·API 키·손님 개인정보를 적지 않는다
  • 안 쓰는 스킬은 끄거나 삭제한다
공식 문서 표현: "직접 만들었거나 Anthropic에서 받은 신뢰할 수 있는 출처의 스킬만 사용", "소프트웨어 설치처럼 취급". 외부 URL에서 내용을 가져오는 스킬은 특히 위험(가져온 내용에 악성 지시가 섞일 수 있음). 2회차 AI 사용 수칙에 "스킬 설치 규칙" 한 줄 추가를 권장.
