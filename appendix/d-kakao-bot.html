실습 1 · 카카오톡 채널 만들기 10분

  1. 카카오비즈니스(business.kakao.com) → 카카오톡 채널 → 새 채널 만들기
  2. 채널 이름 봄날의 꽃, 검색용 아이디, 프로필 사진·소개 입력
  3. 운영 시간: 화~일 10:00–20:00 (월요일 휴무) 설정
  4. 채널 공개·검색 허용 켜기
  5. (필요 시) 채널 관리자센터 → 설정 → 비즈니스 인증에서 사업자등록증으로 신청
비즈니스 인증은 사업자 정보 확인을 거친 채널입니다. 챗봇 플러그인 등 일부 기능은 인증 채널이 필요하고, 심사에 며칠 걸릴 수 있으니 미리 신청하세요.
사업자등록증 사진은 인증 신청 화면에만 올리고, 단톡방·AI 채팅에 붙여 넣지 마세요.

2026-10 기준 메뉴 이름입니다. 화면 개편이 잦으니 수업 전 확인하세요.

사업자가 아직 없는 수강생은 일반 채널로 1·2단계까지 실습 가능. 3단계(스킬·콜백)에서 막히면 비즈니스 인증 여부부터 확인.

실습 2 · 채팅 자동응답 (코딩 없음) 8분

  1. 채널 관리자센터 → 채팅 → 자동응답
  2. 첫 인사(웰컴) 메시지: "AI·자동응답이 먼저 답하고, 필요하면 직원이 이어서 답한다" 안내
  3. 12회차에 만든 FAQ 10개 중 자주 묻는 질문을 자동응답으로 등록
  4. 휴대폰 카카오톡으로 채널 추가 → 직접 질문해 확인
12회차에 만든 LINE 응답 메시지 표(키워드 | 답변)를 카카오톡 채널용으로 바꿔줘. [조건] 한국어만, 각 답변 2~3줄, 존댓말. 영업시간 화~일 10:00–20:00, 월요일 휴무. 모르는 내용은 [확인 필요]. [형식] 표: 질문 | 손님이 쓸 만한 표현 3개 | 답변
한국 AI 기본법(2026-01-22 시행)에 따라 AI가 답한다면 첫 인사에 "AI 상담원"임을 밝히세요.
카카오 채널 자동응답 메뉴 구성(키워드형·버튼형 등)은 자주 바뀜 — 수업 전 강사가 실제 화면을 캡처해 두기. 3단계에서 챗봇을 연결하면 채팅 답변은 챗봇이 맡게 되므로, 자동응답과 챗봇의 우선순위를 확인할 것.

실습 4 · 폴백 블록에 우리 서버 연결 10분

  1. 스킬 → 스킬 목록 → 생성: 이름 봄날의 꽃 AI 서버
  2. 먼저 터미널에서 npx wrangler secret put KAKAO_SKILL_SECRET → 아무도 못 맞힐 긴 문자열 입력 (예: 비밀번호 생성기로 만든 32자)
  3. URL에 14회차 주소 + /kakao/skill?key= + 방금 만든 문자열 붙여넣기 → 저장
  4. 시나리오 → 폴백 블록 → 파라미터 설정의 스킬 선택에서 방금 만든 스킬
  5. 봇 응답을 스킬데이터 사용으로 → 저장
https://bomnal-bot.내계정.workers.dev/kakao/skill?key=내가-만든-긴-비밀문자열
LINE과 같은 서버·같은 상담 규칙(knowledge.ts)을 씁니다. 비밀값은 ANTHROPIC_API_KEY와 KAKAO_SKILL_SECRET이 꼭 필요하고, Slack·Jira 값이 있으면 카카오 문의도 #cs-escalation·BOM으로 넘어갑니다.
카카오는 LINE 같은 서명이 없어서 ?key= 비밀 문자열로 우리 챗봇만 들어오게 막습니다. 이 주소는 비밀번호처럼 다루고, 유출되면 secret put으로 새 값을 넣은 뒤 스킬 URL도 바꾸세요. Anthropic Console의 월 사용 한도도 꼭 걸어 두세요.
"내계정" 부분은 14회차 npx wrangler deploy 끝에 나온 주소. 서버 코드는 examples/messenger-bot/src/kakao.ts — ?key= 값이 틀리면 401로 거절(Claude 호출 안 함), KAKAO_SKILL_SECRET이 없으면 500. 콜백이 켜져 있으면 콜백 방식, 꺼져 있으면 4초 안에 답하거나 "잠시 후 다시 물어봐 달라"는 안내로 답함.

카카오의 5초 규칙과 콜백 7분

⏱️ 5초 규칙

스킬 서버가 5초 안에 답하지 않으면 카카오는 실패로 봅니다. AI는 가끔 5초를 넘깁니다.

📞 콜백

서버가 즉시 "useCallback": true로 "준비 중" 응답 → 답이 나오면 callbackUrl로 보냄. 이 주소는 5분 안에 1번만 사용.

{ "version": "2.0", "useCallback": true,
  "data": { "text": "답변을 준비하고 있어요..." } }
  1. 설정 → AI 챗봇 관리 → AI 챗봇 전환 신청 (승인 후 콜백 사용 가능)
  2. 폴백 블록 → ⋯ 메뉴 → Callback API 설정 켜고 기본 응답 문구 입력

2026-10 기준. 'AI 챗봇 관리' 메뉴가 안 보이거나 승인 조건(비즈니스 인증 등)이 다를 수 있으니 수업 전 확인하세요.

LINE의 reply token(1분)과 비교: 카카오는 5초 + 콜백 5분. 콜백 승인 전에는 우리 서버가 4초 안에 답하거나 안내 문구로 응답하므로 봇은 일단 동작함. 콜백 승인 메뉴가 안 보이는 사례가 Kakao DevTalk에 보고되어 있음 — 그 경우 챗봇 관리자센터 문의.

배포하고 진짜 카카오톡으로 테스트 8분

  1. 배포 → 배포 버튼 (저장만 하면 손님에게 반영되지 않음)
  2. 휴대폰 카카오톡에서 채널 대화방 → 13회차 짓궂은 질문 3개 보내기
  3. 터미널 npx wrangler tail로 로그 확인
증상해결
봇테스트 창에서 콜백 답이 안 옴정상 — 봇테스트는 콜백을 완전히 지원하지 않음. 배포 후 실제 채팅으로 테스트
"잠시 후 다시 물어봐 주세요"만 나옴콜백 미설정 + 답이 4초 초과. 콜백 신청·설정
스킬 오류 / 응답 없음URL 끝 /kakao/skill?key=… 값이 서버의 KAKAO_SKILL_SECRET과 같은지, ANTHROPIC_API_KEY가 있는지 확인 (npx wrangler tail에 401이면 key 불일치, 500이면 비밀값 누락)
채널 연결 목록에 채널이 없음채널 관리자(마스터) 권한, 비즈니스 인증 여부 확인
배포 버튼을 누르지 않아 "고쳤는데 안 바뀐다"는 경우가 가장 흔함. 테스트 후 Slack #cs-escalation에 "카카오 문의" 알림이 오는지도 확인.
