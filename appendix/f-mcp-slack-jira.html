MCP는 AI용 만능 콘센트 7분

해외여행 갈 때 챙기는 만능 어댑터를 떠올려 보세요. 나라마다 콘센트 모양이 달라도 어댑터 하나면 다 꽂히죠. MCP는 AI와 다른 서비스를 잇는 공통 콘센트 규격이고, Slack·Jira마다 하나씩 있는 커넥터는 거기에 꽂는 플러그예요. 플러그를 꽂으면 Claude가 Slack 채널을 읽고, Jira 이슈를 만들 수 있게 됩니다.

BOM 이슈
"MCP" 이름 풀이(Model Context Protocol)는 묻는 사람에게만. 핵심은 콘센트/플러그. 예상 질문: "그럼 Claude가 우리 Slack 전체를 다 보나요?" → 아니요. 로그인한 '내 계정'이 볼 수 있는 범위만, 그리고 대화마다 켜고 끌 수 있음(뒤에서 실습).

실습 1 · Slack 연결하기 10분

  1. 크롬에서 claude.ai › Customize › Connectors 열기
  2. Discover → Search connectors에 Slack 입력
  3. 만든 곳이 Slack이고 Verified 표시인지 확인 → 클릭
  4. Connect to Claude 클릭
  5. Slack 로그인 화면 → 오른쪽 위에서 봄날 에스테틱 워크스페이스 선택
  6. 요청 권한 목록을 읽고 허용(Allow)
  7. Connectors 화면 Your connectors에 Connected가 보이면 성공 🎉
"관리자 승인 필요"가 뜨면 워크스페이스 소유자(원장님)가 먼저 승인해야 해요.
이름이 비슷한 비공식 Slack 커넥터도 있어요. 반드시 Slack이 만든 공식 것을 고르세요.

Slack 공식 서버 주소: https://mcp.slack.com/mcp

2026-10 기준 화면. 버튼 문구는 바뀔 수 있습니다.

막히는 곳: ① 워크스페이스를 여러 개 쓰는 사람이 개인 워크스페이스로 연결 → Disconnect 후 다시. ② 팝업 차단. ③ Team 플랜이면 "Request" 버튼만 보임 → Owner가 Connect for your team. 데스크톱 앱에서는 로그인 페이지가 기본 브라우저로 열림 — 브라우저에 다른 Slack 계정이 로그인돼 있으면 엉뚱한 계정으로 연결됨.

실습 2 · Jira(Atlassian) 연결하기 10분

  1. 같은 화면 Customize › Connectors › Discover에서 Atlassian 검색
  2. 만든 곳이 Atlassian인 커넥터(Atlassian MCP / Rovo) 클릭 → Connect to Claude
  3. Atlassian 계정으로 로그인
  4. 사이트 선택에서 우리 사이트(예: bomnal.atlassian.net) 고르기
  5. 권한 내용 확인 → Accept(수락)
  6. Connected 확인 후 새 채팅에서 "내가 볼 수 있는 Jira 프로젝트 알려 줘" → BOM이 나오면 성공
Jira에서 내가 못 보는 프로젝트는 Claude도 못 봅니다. 권한은 Jira 설정 그대로예요.
무료 Jira도 됩니다. 단, 사이트 전체에 시간당 호출 한도(Free 약 500회)가 있어요 — 평소 사용엔 충분.

2026-10 기준. 호출 한도 수치는 수업 전 Atlassian 문서로 확인하세요.

공식 서버 주소: https://mcp.atlassian.com/v2/mcp (2026-10 권장). 옛 자료의 /v1/sse 주소는 2026-06-30로 지원 종료 — 쓰지 말 것. 안 될 때: Atlassian Administration › Rovo › Rovo MCP server 에서 "Allow Atlassian supported domains"가 꺼져 있으면 claude.ai 연결이 막힘(조직 관리자만 변경 가능). 연결 후 Atlassian 쪽 확인 위치: Administration › Apps › Sites › 사이트 › Connected apps. 레이트리밋(비공식 요약): Free 500/시간, Standard 1,000, Premium+ 1,000+사용자당 20.

권한 설정 · 읽기는 허용, 쓰기는 확인 5분

새로 온 데스크 실장에게 예약 장부 보기는 자유, 하지만 손님께 문자 보내기 전엔 원장 확인을 받게 하는 것과 같아요.
  1. Customize › Connectors → Slack(또는 Atlassian) 클릭
  2. Tool permissions에서 도구 묶음별로 고르기
도구 종류예추천 설정
읽기·검색채널 읽기, 이슈 검색Always allow 항상 허용
쓰기메시지 보내기, 이슈 만들기·수정, 댓글Needs approval 확인 후 허용
위험삭제·관리 기능Blocked 차단
대화 중 뜨는 승인 창에서 Always allow를 습관처럼 누르면 쓰기 도구도 무조건 허용이 됩니다. 쓰기는 Allow once로!
공식 옵션명: Always allow / Needs approval / Blocked (커넥터 페이지 Tool permissions), 대화 중 승인 창은 Allow once / Always allow. 도구가 많으면 묶음(그룹) 단위로 먼저 설정하고 필요한 것만 개별 조정. Jira 쪽은 조직 관리자가 Atlassian Administration에서 삭제 등 특정 작업을 아예 꺼 둘 수도 있음.

실습 3 · 첫 테스트 프롬프트 5개 8분

새 채팅 → 입력창 + › Connectors 에서 Slack·Atlassian 토글을 켠 뒤 하나씩.

Slack #예약 채널에 오늘 올라온 메시지를 요약해 줘. 시간순으로 예약 변경·취소·특이사항만 표로.
Jira BOM 프로젝트에서 이번 주 '관리 완료' 상태인 이슈 목록을 보여 줘. 사후 연락이 필요한 것 표시해 줘.
Jira BOM 프로젝트에 클레임 이슈 만들어 줘. 제목 "리프팅 관리 후 붉은기 문의(K.님)", 담당 원장 한봄, 내용은 3일 후 사후 연락 필요.
Slack #문의 채널에서 지난 7일간 가장 많이 나온 질문 3가지를 알려 줘.
#스탠드업 채널에 올릴 오늘 아침 공지 초안을 써 줘: Jira에서 오늘 '예약 확정' 이슈 수, 알레르기 등 특이 고객은 이니셜로. 보내기 전에 나한테 먼저 보여 줘.
세 번째(이슈 만들기)·다섯 번째(보내기)에서 승인 창이 떠야 정상 → 내용 확인 후 Allow once. 승인 창 없이 바로 만들어졌다면 권한 설정을 다시 볼 것. 고객 이름은 이니셜만 쓰도록 지도. 실습용 워크스페이스에 가짜 메시지를 미리 몇 개 올려 두면 결과가 풍부해짐. Jira 상태 이름이 보드 열과 다르면(예: "관리 완료" vs "Done") Claude가 헷갈림 → 9회차에서 만든 정확한 이름으로.

Claude Code에서 MCP 추가하기 5분

① Jira (Atlassian 공식 서버)

claude mcp add --transport http atlassian https://mcp.atlassian.com/v2/mcp

② Slack (공식 플러그인 — Claude Code 안에서)

/plugin install slack@claude-plugins-official

③ 로그인·상태 확인 (Claude Code 안에서)

/mcp
  • 웹에서 이미 연결했다면 아무것도 안 해도 /mcp 목록에 보여요(claude.ai 계정 로그인 시)
  • 기본은 이 폴더에서 나만(local). --scope user는 내 모든 폴더, --scope project는 .mcp.json 파일로 팀과 공유
  • 목록 보기 claude mcp list · 지우기 claude mcp remove atlassian
.mcp.json에는 주소만 넣고 토큰·비밀번호는 절대 넣지 마세요(Git에 올라갑니다).

2026-10 공식 문서 기준(code.claude.com/docs/en/mcp, github.com/atlassian/atlassian-mcp-server, docs.slack.dev).

Slack 대안 명령(Slack 문서 표기): claude mcp add --transport http --scope local slack https://mcp.slack.com/mcp → /mcp. Slack은 등록 앱의 고정 client ID가 필요해 "dynamic client registration" 오류가 나면 --client-id 1601185624273.8899143856786 --callback-port 3118 추가(플러그인 설정값에서 유도, 수업 전 확인). 초보자에겐 플러그인 또는 웹 연결 공유를 권장. 셸에서 로그인: claude mcp login 이름. 자주 겪는 문제 2분

이럴 때이렇게
Claude가 "Slack에 접근할 수 없어요"입력창 + › Connectors에서 토글이 켜졌는지 확인
Slack에 "관리자 승인 필요"워크스페이스 소유자가 MCP 연결 승인
Jira 프로젝트가 안 보인다다른 사이트로 연결했는지 확인, Jira에서 내 프로젝트 권한 확인
Team 플랜인데 Connect 버튼이 없다Owner가 Organization settings › Connectors에서 먼저 추가
예전 자료의 주소가 안 된다Atlassian은 /v2/mcp 사용 (/v1/sse 종료)
무료 플랜에서 커스텀 커넥터 추가 실패무료는 1개까지. 디렉터리 커넥터를 쓰거나 Pro로
그 밖에: 승인 창이 너무 자주 뜸 → 읽기 도구만 Always allow로. 엉뚱한 채널을 요약함 → 채널 이름을 #까지 정확히. Jira 한도 초과(사이트 전체 시간당) → 잠시 후 다시.

체크리스트 ✅ 1분

  • MCP·커넥터를 콘센트·플러그로 설명할 수 있다
  • Slack 커넥터를 봄날 에스테틱 워크스페이스로 연결했다
  • Atlassian 커넥터를 연결하고 BOM 프로젝트가 보인다
  • 읽기는 Always allow, 쓰기는 Needs approval로 설정했다
  • 테스트 프롬프트 5개를 해 봤다
  • 연결 끊는 곳(Disconnect·Connected apps)을 안다
