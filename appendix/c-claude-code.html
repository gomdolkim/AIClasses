채팅 Claude와 무엇이 다른가요?

claude.ai 채팅은 전화로 조언해 주는 전문가, Claude Code는 사무실에 직접 와서 컴퓨터 앞에 앉아 일하는 기술자예요. 파일을 열어 보고, 새로 만들고, 프로그램을 실행하고, 결과를 확인합니다. 다만 중요한 일은 하기 전에 허락을 구합니다.
Claude Code
내 컴퓨터(또는 클라우드)의 폴더 안에서 직접 파일을 읽고 쓰고 명령을 실행하는 Claude
터미널 (Terminal)
글자로 컴퓨터에 명령하는 창. Mac '터미널', Windows 'PowerShell'
Claude Code는 Pro 이상(Pro·Max·Team·Enterprise) 요금제에 포함됩니다. 무료 요금제에서는 쓸 수 없어요. (2026-10 기준)
ECC 등 개발 도구 이야기 전에 '무엇을 할 수 있는 도구인가'만 확실히. 예: "봄날의 꽃 홈페이지 폴더를 열고, 가격표 부분만 고쳐 줘" → 실제 파일이 바뀜.

14회차 실습 기준

앱·웹의 메뉴 이름과 지원 범위는 2026-10 기준이며 자주 바뀝니다. 수업 전 확인하세요.

공식 문서: 데스크톱 앱은 macOS·Windows·Linux 제공(claude.com/download). 웹은 GitHub 계정 연결이 필요. 세 방법 모두 같은 계정으로 로그인. 터미널에서 /desktop 명령으로 진행 중인 작업을 데스크톱 앱으로 넘길 수도 있음.

설치하기 (터미널 방식)

🍎 Mac (터미널 앱)

curl -fsSL https://claude.ai/install.sh | bash

🪟 Windows (PowerShell)

irm https://claude.ai/install.ps1 | iex
  1. 위 명령을 복사해 붙여넣고 Enter (진행 표시 없이 조용히 설치돼요)
  2. 터미널 창을 닫았다가 새로 열기
  3. claude --version 입력 → 버전 숫자가 나오면 성공
  4. 문제가 있으면 claude doctor로 진단
설치 명령은 반드시 공식 문서(code.claude.com)에서 복사하세요. 블로그·영상에 나온 낯선 주소의 설치 명령은 따라 하지 마세요.

2026-10 공식 문서 기준 권장 방식(네이티브 설치, 자동 업데이트). Homebrew(brew install --cask claude-code), WinGet(winget install Anthropic.ClaudeCode)도 가능.

예전 자료의 npm install -g 방식은 이제 대안일 뿐(Node.js 22+ 필요). sudo npm은 절대 쓰지 말 것. Windows에서 'irm'을 인식 못 하면 CMD 창임 → PowerShell로 열기. Git for Windows 설치를 권장(공식 문서). 'command not found' → 새 터미널을 안 열었거나 PATH 문제 → 공식 Troubleshoot installation 페이지.

첫 실행 · 작업 폴더에서 시작하기

# 1) 작업 폴더 만들고 들어가기
mkdir bomnal-site
cd bomnal-site

# 2) Claude Code 시작
claude
  1. 처음 실행하면 브라우저가 열림 → claude.ai 계정으로 로그인 → 허용
  2. "이 폴더를 믿나요?" 질문 → 내가 만든 폴더면 Yes
  3. 입력창이 나오면 한국어로 말하듯 부탁하면 됩니다
  4. 끝낼 때는 /exit 또는 Ctrl+C 두 번
cd = 폴더로 들어가기, mkdir = 폴더 만들기. 터미널 명령은 이 두 개만 알아도 충분해요. 나머지는 Claude Code에게 부탁하세요.
Claude Code는 '시작한 폴더' 안에서 일함. 바탕화면이나 홈 폴더 전체에서 시작하지 않도록 지도(엉뚱한 파일을 볼 수 있음). 데스크톱 앱 사용자는 폴더 선택 화면에서 같은 폴더를 고르면 됨.

실습 · 첫 작업 맡기기

꽃집 「봄날의 꽃」 한 페이지 홈페이지를 index.html 하나로 만들어 줘. - 영업: 화~일 10:00–20:00, 월요일 휴무 - 위치: 망원역 2번 출구 도보 3분 - 가격: 꽃다발 S 35,000 / M 55,000 / L 85,000원 - 인스타 @bomnal_flower 링크 따뜻한 봄 색감, 휴대폰에서도 보기 좋게.
index.html 파일을 만들까요?
❯ Yes / Yes, 이번 세션 동안 계속 허용 / No
  • 파일을 만들거나 명령을 실행하기 전 허락 질문이 나옵니다
  • 무엇을 하려는지 읽고 승인하세요
  • 완성되면 폴더의 index.html을 더블클릭해 브라우저로 확인
허락 질문의 정확한 문구는 버전마다 다름. "모르는 명령이면 No를 누르고 '이게 뭐 하는 명령이야?'라고 물어보면 된다"가 핵심 습관. 결과가 마음에 안 들면 같은 대화에서 "사진 자리를 더 크게"처럼 이어서 요청.

큰 일은 /plan으로 계획부터

인테리어 기사님께 "바로 벽 뚫어 주세요" 대신 "먼저 도면부터 보여 주세요"라고 하는 것과 같아요.
/plan 홈페이지에 '오늘의 꽃' 섹션과 주문 문의 버튼을 추가하고 싶어

또는 Shift+Tab을 눌러 입력창 아래가 plan mode로 바뀌면 그 상태로 부탁

  1. Claude가 파일을 읽기만 하고 계획표를 보여 줌
  2. 계획을 읽고 고칠 점을 말하기 ("버튼은 인스타 DM으로 연결해 줘")
  3. 괜찮으면 승인 → 그때부터 실제로 파일 수정
/plan은 Claude Code 기본 명령(공식 문서 기준: 입력창에서 바로 plan mode 진입, 뒤에 설명을 붙이면 그 작업으로 시작). 여러 파일을 건드리는 일, 봇 서버 수정 같은 일은 항상 plan 먼저.

Claude Code 안전 수칙

  • 작업 전용 폴더에서만 시작한다 (홈 폴더·바탕화면 전체 X)
  • 허락 질문은 읽고 승인한다. 모르면 No → "이게 뭐야?"
  • 큰 변경은 /plan으로 계획부터 본다
  • 비밀값은 코드·대화에 넣지 않고 .gitignore로 막는다
  • 작업이 잘 끝날 때마다 커밋해 둔다 (부록 B)
  • 출처가 확실한 스킬·플러그인만 설치한다
'항상 허용' 옵션을 습관적으로 누르지 않도록 강조. 특히 삭제(rm), 강제 푸시 같은 명령은 매번 확인.
