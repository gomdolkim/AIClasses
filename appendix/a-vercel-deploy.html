홈페이지를 인터넷에 올리기

6회차에 만든 샵 홈페이지(예약 버튼 포함)에 나만의 인터넷 주소를 달아 줍니다

⌨️ 방향키·스페이스로 이동 · N 강사 노트 · D 어둡게

6회차 아티팩트 공유 링크만으로 충분한 수강생도 많음. "내 주소(도메인)로 운영하고 싶다", "네이버 검색에 걸리게 하고 싶다"는 수강생용 부록. 전체 40~50분.

준비 · 6회차 홈페이지를 파일로 받기

  1. 6회차에 만든 홈페이지 대화(또는 프로젝트)를 엽니다
  2. 오른쪽 프롬프트로 한 파일짜리 HTML을 요청
  3. 아티팩트 화면의 ⋯ → Download(다운로드)로 내려받기
  4. 파일 이름을 정확히 index.html로 바꾸기 (전부 소문자)
이 홈페이지를 그대로 웹사이트에 올리려고 해. CSS와 스크립트를 모두 안에 넣은 index.html 한 파일로 정리해 줘. 사진은 무료 이미지 주소 대신 지금은 빈 칸으로 두고, 나중에 내가 바꿀 위치를 주석으로 표시해 줘. 네이버 예약 버튼과 LINE 버튼 링크는 그대로 살려 줘.
홈페이지에 개인 휴대폰 번호·집 주소가 들어 있지 않은지 확인하세요. 공개되면 누구나 봅니다. 샵 대표번호와 매장 주소만! 고객 전후 사진은 동의서 없이 올리지 마세요.
다운로드 메뉴 위치는 수업 전 확인(2026-10). 메뉴가 안 보이면 코드 보기 → 전체 복사 → 메모장에 붙여넣고 index.html로 저장. Windows는 '파일 확장명 표시'를 켜야 .html.txt가 되는 실수를 막을 수 있음.

실습 1 · GitHub 가입하고 보관함 만들기

  1. github.com → Sign up(가입) → 이메일·비밀번호·사용자 이름 → 이메일 인증
  2. 오른쪽 위 + → New repository(새 저장소)
  3. Repository name: bomnal-esthetic (영어 소문자·하이픈)
  4. Public 선택 → Create repository

💡 저장소(repository) = 프로젝트 폴더

홈페이지 하나당 저장소 하나. 줄여서 "레포"라고도 불러요.

Public(공개) 저장소의 파일은 전 세계 누구나 볼 수 있습니다. 비밀번호·API 키·고객 명단은 절대 올리지 마세요.
가입 시 2단계 인증(2FA) 설정을 요구할 수 있음 — 휴대폰 인증 앱 또는 문자. 사용자 이름은 샵 영문명 추천(예: bomnalesthetic). Private으로 해도 Vercel 배포는 가능하지만 처음엔 Public이 덜 헷갈림.

실습 2 · index.html 올리기

  1. 저장소를 만든 직후 화면의 uploading an existing file 링크 클릭 (또는 Add file → Upload files)
  2. index.html(사진이 있다면 사진 파일도)을 끌어다 놓기
  3. 아래 메모 칸에 "첫 홈페이지 업로드"라고 적기
  4. 초록색 Commit changes 클릭 → 파일 목록에 index.html이 보이면 성공
Commit changes = "이 상태로 저장하고 메모를 남긴다"는 뜻. 나중에 언제 무엇을 바꿨는지 기록이 남아요 (부록 B).
가장 흔한 실수: Index.html, index.html.txt, 폴더째 올려서 index.html이 폴더 안에 들어감. 반드시 저장소 맨 위에 index.html이 있어야 함.

실습 3 · Vercel로 공개하기

  1. vercel.com → Sign Up → Continue with GitHub
  2. GitHub 화면에서 Authorize Vercel(권한 허용)
  3. 대시보드 Add New… → Project
  4. bomnal-esthetic 옆 Import → 설정은 그대로 → Deploy
  5. 1분쯤 뒤 축하 화면과 …vercel.app 주소 확인 🎉

버튼 이름은 2026-10 기준이며 바뀔 수 있습니다. 수업 전 강사가 확인하세요.

⚠️ 샵 홈페이지는 '상업용'입니다

Vercel 무료 요금제(Hobby)는 개인·비상업용입니다. 관리 메뉴·가격을 알리고 예약을 받는 샵 홈페이지는 상업적 이용에 해당하므로, 규정상 유료 Pro 요금제가 필요합니다.
선택지특징
Vercel Pro지금 배운 방법 그대로. 월 요금 발생 (금액은 수업 전 확인)
Cloudflare Pages무료 요금제로 상업용 사이트 가능. GitHub 연결 방식이 거의 같음 — 14회차에서 Cloudflare 계정을 만듦
6회차 아티팩트 공유 링크가장 간단. 내 도메인 연결은 불가

2026-10 Vercel Fair Use Guidelines 기준: 상품·서비스 판매 광고, 결제, 광고 게재 등은 상업적 이용. 요금·규정은 수업 전 확인하세요.

연습·테스트로 잠깐 올려 보는 것은 Hobby로 해도 되지만, 실제 샵 운영용으로 계속 쓰려면 Pro 또는 Cloudflare Pages 권장. 다른 무료 호스팅도 상업 이용 규정은 꼭 확인하도록 안내(GitHub Pages도 상업적 온라인 사업 용도는 제한).

(선택) 나만의 도메인 연결하기

  1. 도메인 구입: Vercel에서 직접, 또는 가비아·호스팅KR(.kr 가능) 등 (.com 기준 보통 연 2만 원 안팎)
  2. Vercel 프로젝트 → Settings → Domains → 도메인 입력 → Add
  3. Vercel이 보여 주는 DNS 값을 도메인 산 곳의 'DNS 설정'에 그대로 입력
  4. 10분~몇 시간 뒤 접속 확인. 자물쇠(🔒 https)는 Vercel이 자동으로 달아 줌
DNS는 인터넷의 전화번호부예요. "bomnal.kr"을 찾으면 "Vercel 전시장 몇 번지"라고 알려 주도록 번호부에 적어 넣는 일이 3단계입니다.
DNS 값(A 레코드, CNAME)은 Vercel 화면에 나온 값을 그대로 복사 — 예전 강의 자료의 값을 외워서 쓰지 말 것. 반영은 최대 48시간까지 걸릴 수 있음. Vercel에서 도메인을 사면 3단계가 자동.
