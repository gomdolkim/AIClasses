파트 A · 프로젝트

프로젝트 = 우리 회사 자료실 5분

신입 비서에게 첫날 자료실 열쇠를 주는 것과 같아요. 자료실 벽에는 "우리 가게는 이렇게 말해요"라는 규칙표가 붙어 있고, 책장에는 FAQ·메뉴 가격표·예약 규정이 꽂혀 있습니다. 그 방에서 하는 대화는 모두 이 자료를 보고 답합니다.
프로젝트 (Project)
대화창 여러 개를 묶고, 자료와 지침을 함께 넣어 두는 '우리 회사 전용 방'
지침 (Instructions)
그 방의 모든 대화에 자동으로 적용되는 규칙 — 말투, 꼭 지킬 것, 하지 말 것

프로젝트 밖의 일반 채팅에서는 이 자료를 모릅니다. "자료실 안에서만 통하는 이야기"라고 기억하세요.

자료실 비유 하나만 쓰기. "RAG", "컨텍스트" 같은 단어는 절대 꺼내지 말 것. 질문이 나오면 "자료가 아주 많아지면 Claude가 필요한 부분만 찾아 읽는다" 정도로만.

😍 프로젝트 안 — 우리 가격·예약 규칙으로 답함

강사가 미리 만들어 둔 「봄날 에스테틱」 프로젝트로 실제 시연. 일반 채팅 → 프로젝트 순서로 같은 질문을 던져 차이를 보여 줌. 답이 화면 예시와 똑같지 않아도 괜찮다고 미리 말해 두기(AI는 매번 표현이 조금씩 다름).

실습 1 · 프로젝트 만들고 말투 지침 넣기 10분

  1. 왼쪽 메뉴 Projects(프로젝트) 클릭 (또는 주소창에 claude.ai/projects)
  2. 오른쪽 위 + New project(새 프로젝트)
  3. 이름: 봄날 에스테틱, 설명: "피부관리 샵 운영 업무용" → 만들기
  4. 오른쪽 Instructions(지침) 칸의 Set project instructions 클릭
  5. 오른쪽 지침을 붙여넣고 Save instructions(저장)
너는 서울 마포구 연남동 피부관리 샵 「봄날 에스테틱」의 업무 비서야. - 말투: 차분하고 따뜻한 존댓말, 짧은 문장. 손님은 "고객님". - 의료·과장 표현 금지: "치료", "완치", "시술", "주름 제거 보장" 쓰지 않기. 필러·보톡스·레이저 문의는 "피부과 상담을 권해 드려요". - 가격·영업시간·예약·회원권 규정은 반드시 첨부한 자료(FAQ, 가격표)대로만 답하고, 자료에 없으면 "확인 후 안내드릴게요"라고 해. - 예약을 확정하거나 환불·할인을 새로 약속하지 마. - 고객 개인정보(전화번호, 카드번호, 피부 질환·임신 여부)는 받거나 적지 마. - 일본인 고객 문의는 일본어 です・ます체로 답해.

메뉴 이름·위치는 2026-10 기준이며 바뀔 수 있습니다. 수업 전 강사가 최신 화면을 확인하세요.

막히는 곳: Projects 메뉴가 안 보임 → 왼쪽 사이드바가 접혀 있음(왼쪽 위 아이콘으로 펼치기). 모바일 앱에서는 만들기보다 PC에서 만들기 권장. 2회차 AI 사용 수칙을 지침 아래에 이어 붙여도 좋다고 안내. 지침은 짧을수록 잘 지킴 — 10줄 안팎 권장.

실습 2 · FAQ·가격표 올리고 시험해 보기 10분

  1. 프로젝트 화면 오른쪽 Files(파일) 칸의 + 클릭
  2. materials/dataset/faq.md, price-list.md 두 파일 올리기 (내 FAQ 메모가 있으면 함께)
  3. 프로젝트 안에서 새 채팅 시작
  4. 오른쪽 질문 3개를 하나씩 던져 보고, 자료와 맞는지 확인
월요일에도 문 열어요?
수분 진정 관리 10회 회원권은 얼마예요?
내일 예약인데 오늘 취소하면 예약금 돌려받아요?
예약 장부·고객 관리 차트처럼 개인정보가 담긴 파일은 올리지 마세요. 특히 피부 질환·알레르기·임신 여부는 건강 관련 민감정보입니다. 꼭 필요하면 이름·전화번호를 지우고(마스킹) 올립니다.
정답: 월요일 휴무 / 595,000원(정가 700,000원에서 15% 할인) / 24시간 전까지는 무료 취소라 예약금 10,000원 환불, 24시간이 지났으면 환불 불가. "언제 예약인지"를 되묻는 답이 오면 아주 좋은 답. 틀리게 답하면 좋은 교재! "자료를 다시 확인해 줘"라고 되묻게 하기. 2회차 할루시네이션 내용과 연결. 파일이 안 올라가면 메모장 내용을 복사해 텍스트로 붙여넣기로 추가해도 됨.

실습 3 · 기본 스킬 켜기 (문서·엑셀 만들기) 7분

  1. 왼쪽 아래 내 이름 → Settings(설정) → Capabilities(기능)
  2. Code execution and file creation(코드 실행 및 파일 생성) 켜기 — 스킬은 이 기능 위에서 움직여요
  3. Customize(사용자 지정) → Skills(스킬) 이동
  4. Anthropic이 만든 기본 스킬(Excel·Word·PowerPoint·PDF) 토글이 켜져 있는지 확인
  5. 시험: 오른쪽 프롬프트 입력 → 엑셀 파일이 만들어지면 성공
봄날 에스테틱 메뉴 가격표를 엑셀 파일로 만들어줘. 메뉴명, 시간, 1회 가격, 10회 회원권 가격 4열로.
기본 스킬은 따로 부르지 않아도 됩니다. "엑셀로", "워드 문서로"라고 말하면 Claude가 알아서 꺼내 씁니다.

스킬은 Free·Pro·Max·Team·Enterprise에서 쓸 수 있습니다(2026-10, 도움말 기준). 메뉴 위치가 자주 바뀌니 수업 전 확인하세요. Team 요금제는 관리자가 먼저 허용해야 합니다.

막히는 곳: Customize 메뉴가 안 보임 → 예전 화면은 Settings 안에 Skills가 있었음. 화면 검색(Ctrl/Cmd+F)으로 "Skills" 찾기. Team 요금제 수강생: Organization settings에서 관리자가 코드 실행·Skills를 켜야 함. 엑셀 파일은 4회차에서 본격적으로 다루니 여기서는 "만들어진다"만 확인.

실습 4 · 공지문 매뉴얼 스킬 설치하기 10분

  1. 강사가 나눠 준 bomnal-notice-writer.zip 내려받기 (압축은 풀지 마세요)
  2. Customize(사용자 지정) → Skills(스킬)
  3. + → Create skill → Upload a skill(스킬 업로드)
  4. zip 파일 선택 → 목록에 bomnal-notice-writer가 보이고 토글이 켜지면 성공 🎉
bomnal-notice-writer.zip
└── bomnal-notice-writer/     ← 폴더째 압축
    ├── SKILL.md              ← 매뉴얼 본문
    └── references/
        └── shop-facts.md     ← 메뉴·예약 규정
직접 묶을 때는 폴더를 오른쪽 클릭 → Mac "압축" / Windows "ZIP 파일로 압축". SKILL.md만 압축하면 올라가지 않아요.
스킬 안에는 AI가 따르는 지시문과 프로그램이 들어 있을 수 있습니다. 인터넷에서 받은 출처 모를 스킬은 설치하지 마세요. 직접 만들었거나 믿을 수 있는 곳의 것만!
파일: examples/skills/bomnal-notice-writer.zip (단톡방·USB로 미리 배포). 설치 전에 SKILL.md를 화면에 띄워 "그냥 한글 문서"임을 보여 주면 두려움이 줄어듦. 오류가 나면 거의 다 zip 구조 문제(압축 풀었다가 다시 묶으면서 폴더가 한 겹 더 생김). 강사 zip을 다시 받게 하기. Mac에서 다운로드하면 자동으로 압축이 풀리는 경우가 있음 → 휴지통에서 zip 꺼내기 또는 강사 zip 재배포.
