실습 1 · 긴 PDF 한 장으로 요약하기 9분

  1. 프로젝트 안에서 새 채팅 열기
  2. 입력창 + → 파일 업로드로 PDF 올리기 (거래처 단가표, 매장 임대 계약서, 정부 지원사업 공고 등)
  3. 아래 프롬프트 보내기
  4. 요약에 나온 날짜·금액을 원문에서 찾아 확인
이 PDF를 꽃집 사장님 입장에서 요약해줘. ① 꼭 알아야 할 것 5줄 ② 마감일·금액 표 ③ 나에게 불리하거나 주의할 조항. 원문 몇 쪽에 있는지도 적어줘.
계약서·공고 해석은 참고용입니다. 돈이 걸린 결정은 원문과 전문가로 확인하세요.
PDF가 없는 수강생: 소상공인 지원사업 공고 PDF를 미리 1개 준비해 단톡방에 올려 두기. "몇 쪽에 있는지 적어줘"는 할루시네이션 확인용 장치 — 2회차와 연결. 스캔한 이미지 PDF는 글자 인식이 부정확할 수 있음.

실습 2 · 주간 매출 요약 만들기 10분

  1. materials/dataset/orders-sample.csv 내려받기 (바로 받기)
  2. 프로젝트 채팅에 올리고 데모 프롬프트 붙여넣기
  3. 이어서 아래처럼 질문을 바꿔 가며 물어보기
배송지역별 주문 건수를 많은 순으로 정리하고, 무료 배송 지역(마포·서대문)과 유료 지역을 나눠줘.
요일별 매출을 표로 만들고, 가장 바쁜 요일을 알려줘.
이 요약을 직원 단톡방에 올릴 5줄 공지로 바꿔줘.
결과물 ① "주간 매출 요약" 완성 단계. 마지막 5줄 공지를 저장하게 할 것. 막히는 지점: 다운로드한 파일 위치를 못 찾음(다운로드 폴더) → 끌어다 놓기로 해결. 한글이 깨져 보이면 Claude는 대체로 잘 읽음. 엑셀에서 열 때만 깨지는 경우가 많음.

실습 3 · 영수증 사진을 표로 10분

  1. 휴대폰 Claude 앱에서 + → 카메라로 영수증 촬영 (또는 사진 선택)
  2. 여러 장이면 한 번에 올려도 됩니다
  3. 아래 프롬프트 보내기
  4. 합계를 영수증 실물과 비교
이 영수증들을 표로 정리해줘. 열: 날짜, 가게, 품목, 금액, 분류(꽃 재료/포장재/배송/기타). 맨 아래 분류별 합계. 글자가 흐려서 확실하지 않은 칸은 [확인 필요]로 표시해줘.
영수증에 찍힌 카드번호·승인번호는 촬영 전에 손가락이나 포스트잇으로 가리세요.
밝은 곳에서, 영수증을 펴서, 위에서 수직으로 찍으면 인식률이 크게 올라감. 표가 완성되면 "엑셀 파일로 만들어줘" → 내려받기 버튼이 생기는지 시연(파일 생성 기능, 2026-10 기준 수업 전 확인). 세무 신고용 장부를 대체하는 건 아니라고 한마디.

② 건수 세기

③ 하나 골라 보기

아무 주문 1건을 골라 표에 제대로 들어갔는지

2회차에서 배운 것처럼, AI는 숫자를 자신 있게 틀릴 수 있습니다. 세금·급여·매출 보고에 쓰는 숫자는 꼭 검산하세요.
엑셀이 없는 수강생은 Google 스프레드시트에서 CSV를 열어 합계 확인. 실제로 틀린 경우가 나오면 좋은 교육 기회 — 화면에 공유.

실습 4 · 견적서 양식 만들기 10분

회사 행사용 꽃 견적서 양식을 만들어줘. - 받는 곳: (주)망원상사 총무팀 / 개업 화환 2개(120,000원), 꽃바구니 3개(70,000원), 배송비 5,000원 - 항목: 견적번호, 날짜, 받는 곳, 품목·수량·단가·금액 표, 합계, 유효기간 7일, 환불 규칙(제작 시작 전 전액 환불, 제작 후 불가) - 빈칸은 다음에 내가 채울 수 있게 [ ] 로 남겨줘 - 엑셀 파일로도 만들어줘
합계 칸이 수식으로 되어 있으면, 다음부터 수량만 바꿔도 자동 계산됩니다. "합계는 엑셀 수식으로 넣어줘"라고 덧붙여 보세요.
정답 합계: 240,000 + 210,000 + 5,000 = 455,000원
결과물 ② "견적서 양식". 부가세 포함 여부를 물어오는 수강생이 있음 → 가게 사정에 맞게 조건에 추가하라고 안내. 엑셀 파일 생성이 안 되면 표를 복사해 엑셀에 붙여넣는 방식으로 대체. 완성된 양식은 다음 단계에서 프로젝트 지식에 넣음.

자주 겪는 문제 4분

이럴 때이렇게
파일이 너무 크다고 나온다필요한 기간·열만 남겨 저장하거나, 여러 개로 나눠 올리기
엑셀 시트가 여러 개인데 하나만 읽었다"모든 시트를 읽어줘" 또는 시트 이름을 지정
합계가 내 계산과 다르다"전체 몇 줄 읽었는지, 계산 과정을 보여줘" → 빠진 줄 찾기
영수증 글자를 잘못 읽었다밝은 곳에서 다시 촬영, [확인 필요] 칸만 직접 고치기
엑셀 파일 내려받기 버튼이 없다설정의 파일 생성 기능 확인, 안 되면 표 복사 → 엑셀 붙여넣기
파일 크기·개수 한도는 2026-10 기준으로 수업 전 확인. 자세한 대응은 materials/troubleshooting.html.
