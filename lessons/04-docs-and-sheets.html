실습 파일: materials/dataset/reservations-sample.csv (전체 50건, 위 화면은 일부 예시). 프로젝트 채팅에서 + → 파일 업로드. 정답(강사용): 완료 40건 매출 3,170,000원 / 수분 진정 17건 1,190,000원(1위) / 노쇼 4건 ÷ 50건 = 8% / 재방문 29 ÷ 40 = 72.5%. Claude가 코드를 실행해 계산하는 장면(분석 중… 표시)을 보여 주며 "계산기를 꺼내 쓰는 비서"라고 설명. 설정에서 코드 실행/파일 생성 기능이 꺼져 있으면 계산을 머릿속으로 해서 틀릴 수 있음 → Settings(설정) → Capabilities(기능) 확인(2026-10 기준, 수업 전 확인).

실습 1 · 긴 PDF 한 장으로 요약하기 9분

  1. 프로젝트 안에서 새 채팅 열기
  2. 입력창 + → 파일 업로드로 PDF 올리기 (화장품 거래처 단가표, 매장 임대 계약서, 정부 지원사업 공고 등)
  3. 아래 프롬프트 보내기
  4. 요약에 나온 날짜·금액을 원문에서 찾아 확인
이 PDF를 1인 피부관리 샵 원장 입장에서 요약해줘. ① 꼭 알아야 할 것 5줄 ② 마감일·금액 표 ③ 나에게 불리하거나 주의할 조항. 원문 몇 쪽에 있는지도 적어줘.
계약서·공고 해석은 참고용입니다. 돈이 걸린 결정은 원문과 전문가로 확인하세요.
PDF가 없는 수강생: 소상공인 지원사업 공고 PDF를 미리 1개 준비해 단톡방에 올려 두기. "몇 쪽에 있는지 적어줘"는 할루시네이션 확인용 장치 — 2회차와 연결. 스캔한 이미지 PDF는 글자 인식이 부정확할 수 있음.

실습 2 · 예약·매출 요약 만들기 10분

  1. materials/dataset/reservations-sample.csv 내려받기 (바로 받기)
  2. 프로젝트 채팅에 올리고 데모 프롬프트 붙여넣기
  3. 이어서 아래처럼 질문을 바꿔 가며 물어보기
요일별·시간대별 예약 건수를 표로 만들고, 가장 붐비는 요일과 시간대를 알려줘. 관리사 3명 근무표를 짤 때 참고할 점도.
노쇼가 난 예약만 모아서 요일·시간·채널·신규 여부에 공통점이 있는지 봐줘. 노쇼를 줄일 방법 3가지도.
이 요약을 직원 단톡방에 올릴 5줄 공지로 바꿔줘.
결과물 ① "예약·매출 요약" 완성 단계. 마지막 5줄 공지를 저장하게 할 것. 정답(강사용): 예약 건수는 금요일 13건이 최다, 19시대 15건 / 노쇼 4건이 모두 저녁 19:00 예약이고 그중 3건이 신규 → "신규 저녁 예약은 전날 리마인드 + 예약금" 같은 대책이 나오면 7회차 흐름도(전날 리마인드)로 연결. 막히는 지점: 다운로드한 파일 위치를 못 찾음(다운로드 폴더) → 끌어다 놓기로 해결. 한글이 깨져 보이면 Claude는 대체로 잘 읽음. 엑셀에서 열 때만 깨지는 경우가 많음.

실습 3 · 영수증 사진을 표로 10분

  1. 휴대폰 Claude 앱에서 + → 카메라로 영수증 촬영 (또는 사진 선택)
  2. 여러 장이면 한 번에 올려도 됩니다
  3. 아래 프롬프트 보내기
  4. 합계를 영수증 실물과 비교
이 영수증들을 표로 정리해줘. 열: 날짜, 거래처, 품목, 금액, 분류(관리용 화장품/일회용 소모품/수건·린넨 세탁/기타). 맨 아래 분류별 합계. 글자가 흐려서 확실하지 않은 칸은 [확인 필요]로 표시해줘.
영수증에 찍힌 카드번호·승인번호는 촬영 전에 손가락이나 포스트잇으로 가리세요.
밝은 곳에서, 영수증을 펴서, 위에서 수직으로 찍으면 인식률이 크게 올라감. 표가 완성되면 "엑셀 파일로 만들어줘" → 내려받기 버튼이 생기는지 시연(파일 생성 기능, 2026-10 기준 수업 전 확인). 세무 신고용 장부를 대체하는 건 아니라고 한마디.

실습 4 · 관리 차트 + 회원권 잔여 횟수 표 만들기 10분

두 가지 양식을 엑셀 파일 하나에 시트 2개로 만들어줘. [시트1 관리 차트(고객 카드)] 고객번호(예: A-012), 첫 방문일, 피부 타입, 주의사항(알레르기·사용 금지 성분), 방문일별 기록(날짜·관리 메뉴·담당 관리사·사용 제품·관리 후 상태·다음 관리 제안). 이름·전화번호 칸은 만들지 마. [시트2 회원권 잔여 횟수] 고객번호, 메뉴, 구매일, 결제액, 총 횟수(10), 사용 횟수, 잔여 횟수, 환불 시 예상액(사용 횟수 × 정가를 빼고 남은 금액의 10% 위약금 차감). - 잔여 횟수와 환불 예상액은 엑셀 수식으로 넣어줘 - 예시 1줄: A-012, 수분 진정 관리, 595,000원, 사용 3회 (정가 70,000원)
칸이 수식으로 되어 있으면, 다음부터 사용 횟수만 바꿔도 잔여 횟수가 자동 계산됩니다.
정답: 잔여 7회 / 환불 예상액 (595,000 − 210,000) × 0.9 = 346,500원
관리 차트의 피부 상태·알레르기는 민감정보입니다. AI에는 빈 양식만 만들게 하고, 실제 고객 기록은 샵 컴퓨터에만 채우세요. 고객번호와 이름을 잇는 명단은 따로 보관합니다.
결과물 ② "관리 차트·회원권 양식". 환불 예상액을 할인가 기준으로 잘못 넣는 경우가 많음 → 2회차 검산 습관과 연결. 실제 환불 금액 확정은 원장이 직접. 예상 질문: "종이 차트를 사진 찍어 올려서 정리하면 안 되나요?" → 실명·질환이 담긴 차트는 올리지 않기. 민감정보 처리 동의 등 법적 요건은 수업 전 확인. 엑셀 파일 생성이 안 되면 표를 복사해 엑셀에 붙여넣는 방식으로 대체. 완성된 양식은 다음 단계에서 프로젝트 지식에 넣음.
