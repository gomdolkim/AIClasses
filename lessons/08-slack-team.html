Slack = 방이 나뉜 우리 샵 7분

단톡방은 데스크·관리실·상담실 사람이 모두 한 방에서 동시에 떠드는 것과 같습니다. Slack은 예약 데스크·상담실·공지 게시판처럼 방을 나눈 샵이에요. 필요한 방에만 들어가면 됩니다.
워크스페이스 (Workspace)
우리 회사 전용 Slack 건물. 주소는 bomnal-esthetic.slack.com처럼 생김
채널 (Channel)
주제별 방. 이름 앞에 # 이 붙음 (#예약, #문의)
스레드 (Thread)
메시지 하나에 달리는 댓글 줄. 대화가 채널을 덮지 않게 해 줌
워크플로 (Workflow)
"언제 ~하면 ~한다"를 Slack 안에서 자동으로 해 주는 작은 봇
새 용어 4개. 멘션(@)과 이모지 반응은 실습에서 자연스럽게 익힘. "워크플로 = 7회차의 트리거→액션"이라고 연결해 주기.

실습 1 · 워크스페이스 만들기 8분

  1. 크롬 주소창에 slack.com → 시작하기(Get started)
  2. 샵 대표 메일 입력 → 메일로 온 6자리 코드 입력
  3. 워크스페이스 만들기(Create a workspace) → 회사 이름 "봄날 에스테틱"
  4. 내 이름·사진 설정 → 팀원 초대는 건너뛰기 (채널부터 만들고 초대)
  5. 플랜 선택 화면: Pro (체험이 보이면 체험으로 시작)
  6. 컴퓨터용 Slack 앱과 휴대폰 앱 설치 후 로그인 (관리사는 휴대폰 앱이 주로 쓰임)
Pro: 사용자당 월 $7.25(연간) / $8.75(월간). 무료 플랜은 기록 90일·앱 10개 제한이 있습니다.
Workflow Builder(실습 3)는 도움말상 유료 플랜 기능입니다. 가격 페이지 표기와 다를 때가 있어 수업 전 확인이 필요합니다.

요금·화면은 2026-10 기준이며 바뀔 수 있습니다. Pro 무료 체험 제공 여부와 기간은 수업 전 확인하세요.

막히는 곳: 코드 메일이 스팸함에, 이미 다른 회사 Slack에 같은 메일로 가입돼 있어 화면이 다름 → "새 워크스페이스 만들기" 찾기. 결제가 안 된 수강생은 무료 플랜으로 계속 진행하고, 실습 3은 강사 화면을 보며 따라 하기.

봄날 에스테틱 채널 설계 6분

채널무엇을 올리나누가알림
#공지휴무·가격 변경·시즌 이벤트·주간 보고원장만 글쓰기모든 메시지
#예약새 예약·변경·취소, 노쇼, 관리 완료·사후 연락 알림전원멘션만
#문의손님 문의 공유(가격·회원권·주차 등), 답변 상의전원멘션만
#스탠드업매일 10:30 오늘 예약 수·특이 고객·할 일전원 + 워크플로멘션만
#cs-escalation봇이 사람에게 넘기는 문의: 트러블 호소·환불·불만 (13회차~)봇 + 원장모든 메시지 🔔
채널은 적을수록 좋습니다. "이 글 어디 올리지?" 고민이 생기면 채널이 너무 많은 거예요.
채널 이름은 한글 가능. 단, 나중에 자동화에서 채널을 고를 때 한글이 검색 안 되는 화면이 가끔 있음 → 그때는 영어 이름(booking, cs-escalation)으로 바꿔도 됨. #cs-escalation은 전 회차 공통 이름이니 그대로 쓰게 하기. 예상 질문: "회원권 관련은요?" → #문의에서 다루고, 환불 요청만 원장에게(#cs-escalation).

실습 2 · 채널 5개 만들고 팀원 초대하기 7분

  1. 왼쪽 사이드바 채널 추가(Add channels) → 채널 만들기(Create a new channel)
  2. 이름 "예약" → 공개(Public) 선택 → 만들기
  3. 같은 방법으로 공지·문의·스탠드업·cs-escalation
  4. #cs-escalation 채널 이름 클릭 → 알림(Notifications) → 모든 새 메시지(All new messages)
  5. 사이드바 팀원 초대(Invite people) → 지수·유나·민호 메일 입력
#공지는 채널 설정에서 글쓰기 권한을 원장만으로 제한할 수 있습니다(플랜·권한에 따라 메뉴가 다를 수 있음).
손님 전화번호는 "010-****-1234"처럼 가리고, 이름은 성이나 이니셜만. 피부 질환·알레르기·임신 여부는 건강 관련 민감정보라 채널에 이름과 함께 쓰지 않습니다. 나중에 Claude가 채널을 읽게 되기 때문입니다.
초대는 수업 중 실제로 보내도 되고, 과제로 넘겨도 됨. 팀원이 없는 수강생은 개인 메일 하나를 더 초대해 테스트. 민감정보 규칙은 2회차 내용 복습 — 상세 내용은 원래 쓰던 고객 카드(관리 차트)에만 적는다.

우리 에스테틱 샵 팀 Slack 사용 규칙을 #공지에 고정할 글로 써줘. [상황] 직원 4명(원장, 관리사 2명, 예약·데스크 실장 1명), 채널은 #공지 #예약 #문의 #스탠드업 #cs-escalation [조건] 예약 1건=메시지 1개, 변경은 스레드로, 부탁은 @멘션, 👀=확인 중 ✅=확정/완료 🚨=급함 🙅=노쇼. 손님은 성·이니셜만, 전화번호 가리기, 피부 질환·알레르기·임신 여부는 Slack에 쓰지 말고 고객 카드에만. 친근한 말투, 10줄 이내 [형식] 제목 + 번호 목록
Claude가 쓴 규칙을 #공지에 올리고 메시지 ⋯ → "채널에 고정(Pin)". 🙅 노쇼 이모지는 11회차 주간 보고의 노쇼 집계로 이어짐(Jira 쪽은 9회차에서 라벨로 표시).

실습 3 · 매일 10:30 스탠드업 워크플로 만들기 14분

  1. 사이드바 더 보기(More) → 자동화(Automations) 또는 도구(Tools) → 워크플로(Workflows)
  2. 새 워크플로(New workflow) → 이름 "매일 스탠드업"
  3. 시작 방법: 일정에 따라(On a schedule) → 시간 10:30, 반복 매주 화~일, 시간대 서울
  4. 단계 추가(Add steps) → 메시지(Messages) → 채널에 메시지 보내기 → #스탠드업
  5. 메시지 내용에 오른쪽 문구 붙여넣기
  6. 게시(Publish) → 강사 신호에 맞춰 시간을 1분 뒤로 바꿔 테스트 후 10:30으로 되돌리기

이 메시지의 스레드에 남겨 주세요.

2026-10 기준. Workflow Builder 사용 가능 플랜·메뉴 경로는 수업 전 확인.

가장 오래 걸리는 실습. 막히는 곳: 메뉴를 못 찾음(플랜 문제일 가능성 → 무료 플랜이면 메뉴가 없거나 잠겨 있음), 시간대가 서울이 아님, 반복 요일 설정. "특이 고객"은 이니셜 + 한 단어만 — "김○○ 아토피 심함" 같은 글이 올라오면 그 자리에서 고쳐 주기(민감정보). 빨리 끝난 수강생: 단계에 "양식(Form)"을 추가해 예약 수를 숫자 칸으로 받아 보기(선택).

실습 4 · Claude에 Slack 연결해서 요약 받기 10분

  1. claude.ai → 왼쪽 아래 이름 → 설정(Settings) → 커넥터(Connectors)
  2. 목록에서 Slack → 연결(Connect)
  3. Slack 로그인 화면에서 "봄날 에스테틱" 워크스페이스 선택 → 허용(Allow)
  4. 새 채팅 → 입력창 아래 도구 메뉴에서 Slack이 켜져 있는지 확인
  5. #예약에 연습용 예약 메시지를 3개쯤 올린 뒤 아래 프롬프트 실행
    예: "K님 · 수분 진정 60분 · 14:00 · 지수 · 네이버 예약금 확인"
Slack #예약 채널의 오늘 메시지를 읽고 요약해줘. - 예약별 표: 시간 / 관리 메뉴 / 손님 이니셜 / 담당 관리사 / 상태(이모지 기준) - 같은 관리사의 시간이 겹치는 예약, 담당자가 없는 예약은 따로 표시 - 내일 예약 중 전날 리마인드가 필요한 목록 - 내가 직접 확인해야 할 일 3줄
연결하면 Claude가 내가 볼 수 있는 채널을 읽을 수 있습니다. 개인정보·건강정보는 가려 쓰는 규칙을 꼭 지키세요. 메시지를 보낼 때는 Claude가 먼저 확인을 묻습니다.

커넥터 화면·이름은 2026-10 기준. 회사 Slack에서 앱 설치에 관리자 승인이 필요할 수 있으니 수업 전 확인.

막히는 곳: 워크스페이스 관리자 승인 요청이 뜸(수강생이 관리자이면 바로 승인), 다른 회사 Slack을 선택함. 예상 질문: "Claude가 알아서 글을 올리나요?" → 아니요, 보내기 전에 확인을 받음. 요약 결과의 시간·건수는 원문과 한 번 맞춰 보게 하기(2회차 복습). 관리 시간(60·70·80분)을 고려해 겹침을 찾는지도 확인.

응용 실습 · 우리 샵 채널 설계하기 7분

7회차 흐름도를 Claude에게 보여 주고 우리 샵 채널을 설계해 보세요.

첨부한 흐름도는 우리 샵 업무야. 직원은 ○명이고 업종은 ○○(예: 에스테틱·네일·헤어)야. Slack 채널을 5개 이내로 설계해줘. 표: 채널 이름 / 올릴 내용 / 글쓰는 사람 / 알림 설정 추천 그리고 매일 오픈 전에 자동으로 물어보면 좋을 질문 3개를 추천해줘. 고객 건강정보를 묻는 질문은 빼줘.
봄날 에스테틱 채널 이름 중 #cs-escalation은 13회차 봇과 연결되니 회사가 달라도 그대로 만들어 두세요.
시간이 남으면 실제로 자기 워크스페이스에 채널을 추가. 결과 표는 14회차 도입 계획서에 씀.
