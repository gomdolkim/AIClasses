홈페이지 = 인터넷에 세운 가게 간판 7분

홈페이지는 24시간 켜져 있는 가게 간판 겸 안내 책자입니다. 예전엔 간판집(제작 업체)에 맡겨야 했지만, 이제는 Claude에게 "이런 간판 만들어 줘"라고 말하면 옆 작업대(아티팩트)에 바로 만들어 줍니다. 다 되면 공개 링크를 명함처럼 손님에게 건네면 끝!
홈페이지 (웹사이트)
인터넷 주소로 누구나 열어 볼 수 있는 화면. 오늘은 1페이지짜리 소개 사이트
아티팩트 (Artifacts)
Claude가 대화창 오른쪽에 따로 만들어 주는 결과물 창. 홈페이지·문서·표 등을 바로 보여 줌
공개 링크
아티팩트를 Publish(게시)하면 생기는 인터넷 주소. 링크를 받은 사람은 Claude 계정 없이도 볼 수 있음
HTML·CSS 같은 말은 꺼내지 않는다(옛 1강 덱과 다른 점). "Claude가 홈페이지 설계도를 써 주고 바로 지어 준다" 정도로 충분. 예상 질문: "이걸로 네이버 검색에 나오나요?" → 공개 링크는 검색 노출을 보장하지 않음. 제대로 된 내 도메인·검색 등록은 부록 A.

강사 데모 · 부탁 한 번에 홈페이지 6분

프로젝트에 있는 가게 정보와 말투 가이드를 바탕으로, 꽃집 「봄날의 꽃」 1페이지 소개 홈페이지를 아티팩트로 만들어줘. - 순서: 첫 화면(가게 이름 + 한 줄 소개 + '주문하기' 버튼) → 상품과 가격 → 당일 배송 안내 → 영업시간·오시는 길 → 연락처 - 분위기: 파스텔 분홍과 연두, 따뜻하고 깔끔하게 - 휴대폰에서 보기 좋게 - 가격·영업시간은 프로젝트 자료에 있는 것만 쓰고, 모르는 정보는 [확인 필요]로 남겨줘

실습 1 · 홈페이지 재료 한 장 정리 7분

  • 가게 이름과 한 줄 소개 (1회차 소개문)
  • 대표 상품 3~5개와 가격
  • 영업시간·휴무일·주소·찾아오는 길
  • 가게 대표 전화 (개인 휴대폰 X)
  • 네이버 지도 링크
  • 주문 링크 (스마트스토어 등)
  • 인스타·LINE 링크
공개 링크는 누구나 볼 수 있습니다. 대표 개인 휴대폰 번호, 집 주소, 직원 실명·사진은 넣지 마세요.
링크 복사법: 네이버 지도 앱에서 가게 검색 → 공유 → 링크 복사. 스마트스토어·인스타도 공유 버튼에서 복사.
메모장에 한 번에 모아 두면 이후 실습이 빨라짐. 봄날의 꽃 그대로 하는 수강생은 링크를 비워 두고 [확인 필요]로. "대표 전화"가 없는 1인 사업자는 문의를 인스타 DM·LINE으로 받는 방식 추천.

실습 2 · 내 첫 홈페이지 만들기 10분

  1. 프로젝트 안에서 새 채팅 열기
  2. 데모 프롬프트를 복사해, 가게 이름·분위기·순서를 내 회사로 바꾸기
  3. 실습 1의 재료 메모를 그 아래에 붙여넣고 보내기
  4. 오른쪽 아티팩트 창에서 Preview(미리보기)로 확인
  5. 버튼을 눌러 보고, [확인 필요] 칸이 어디인지 표시해 두기
처음부터 완벽하지 않아도 됩니다. "일단 만들고, 고친다"가 오늘의 순서예요.
막히는 지점: 아티팩트 대신 긴 글(코드)만 대화창에 나옴 → "아티팩트로 보여줘"라고 다시 말하기. 사용량 한도 메시지가 뜨면 옆 사람 화면으로 같이 진행. 다 된 사람은 "다른 분위기 버전도 하나 더" 요청해 비교.

실습 3 · 고쳐 달라고 하기 10분

같은 대화에서 한 번에 하나씩 말하면 결과가 깔끔합니다.

첫 화면 배경을 연한 분홍으로, 글자는 더 크게 바꿔줘.
상품 부분을 카드 3개로 나누고, 각 카드에 꽃 이모지를 넣어줘.
맨 아래에 '월요일 휴무' 안내 띠를 추가해줘.
이전 모습이 더 좋았다면? 아티팩트 창 아래쪽의 버전 화살표(‹ ›)로 앞 버전으로 돌아갈 수 있어요.
사진을 올려서 "이 사진 분위기에 맞는 색으로 바꿔줘"도 가능합니다. 단, 올린 사진이 사이트에 그대로 들어가지 않을 수 있어요.
1회차 "고쳐 달라고 하기"의 반복. 여러 요청을 한 문장에 몰아넣으면 일부가 빠지기 쉬움. 사진: 아티팩트 화면에는 업로드한 사진이 바로 들어가지 않는 경우가 많음(2026-10 기준, 수업 전 확인) → 이모지·색으로 꾸미고, 실제 사진은 인스타 링크로 연결. 사진까지 넣은 정식 사이트는 부록 A. 버전 화살표 위치는 화면 업데이트에 따라 바뀔 수 있음.

지도·주문 링크 연결하기 8분

아래 링크를 버튼으로 연결해줘. 버튼을 누르면 새 창에서 열리게 해줘. - '길찾기' 버튼: (네이버 지도 링크 붙여넣기) - '주문하기' 버튼: (스마트스토어 링크 붙여넣기) - '인스타 구경하기' 버튼: (인스타 링크 붙여넣기) - '전화하기' 버튼: 휴대폰에서 누르면 바로 전화가 걸리게 02-000-0000
Claude는 우리 가게의 진짜 링크를 모릅니다. 링크를 알아서 만들어 넣었다면 그럴듯한 가짜 주소일 수 있어요(2회차 할루시네이션). 반드시 내가 복사한 링크를 붙여넣고, 버튼을 직접 눌러 확인하세요.

지도를 화면 안에 넣는 것(지도 퍼가기)은 아티팩트에서 막혀 있을 수 있어요. 버튼으로 연결하는 방식이 가장 확실합니다.

02-000-0000은 예시. 수강생은 가게 대표번호로. LINE 친구 추가 링크는 12회차에서 만든 뒤 다시 넣어도 됨. 미리보기에서 링크가 안 열리면 공개(Publish) 후 다시 확인 — 미리보기 창은 외부 링크를 막는 경우가 있음.

실습 4 · 공개 링크 만들기 8분

  1. 아티팩트 창 오른쪽 위 Publish(게시) 누르기 (화면에 따라 Share(공유)로 보일 수 있음)
  2. 안내를 읽고 공개 확인
  3. 링크 복사 → 카톡 '나에게 보내기'
  4. 내용을 고친 뒤에는 다시 Publish를 눌러 최신 버전으로 업데이트
공개 링크는 링크를 아는 누구나 볼 수 있고, 검색엔진에 노출될 수도 있습니다. 내리고 싶으면 같은 메뉴에서 Unpublish(게시 취소).
Team·Enterprise 요금제의 Share는 회사 구성원끼리만 볼 수 있는 경우가 있어요. 손님용 링크는 개인 Pro 계정에서 Publish가 확실합니다.

2026-10 기준 Free·Pro·Max에서 Publish 가능, 링크 형태 claude.ai/public/artifacts/… 버튼 이름·위치는 수업 전 확인.

수업 직전 강사 계정으로 Publish 버튼 위치를 반드시 재확인(화면 개편이 잦음). 링크를 받은 사람이 '수정해서 내 것으로 만들기(Remix/Customize)'를 할 수 있지만 원본은 바뀌지 않는다고 안내. 예상 질문: "돈이 드나요?" → 추가 비용 없음(2026-10 기준). "주소를 bomnal.com처럼 바꿀 수 있나요?" → 아티팩트로는 불가, 부록 A.

휴대폰으로 확인하기 5분

손님 대부분은 휴대폰으로 링크를 엽니다.

① 열어 보기

카톡 '나에게 보내기'로 보낸 링크를 휴대폰에서 누르기

② 눌러 보기

길찾기·주문·전화 버튼이 모두 제대로 열리는지

③ 읽어 보기

글자가 너무 작거나 옆으로 잘리는 곳이 없는지

휴대폰에서 보니 가격 표가 옆으로 잘려. 휴대폰에서는 표 대신 세로 카드로 보이게 바꿔줘.
짝을 지어 서로의 링크를 열어 주면 "남이 보는 화면" 확인이 됨. 고친 뒤 다시 Publish해야 링크에 반영된다는 점을 다시 강조.

응용 실습 · 우리 가게 사이트 완성하기 8분

  1. [확인 필요] 칸을 모두 진짜 정보로 채우기
  2. 말투 가이드에 맞게 문구 다듬기
  3. 다시 Publish → 휴대폰으로 최종 확인
  4. 링크를 인스타 프로필·LINE 공지·명함 QR에 쓸 수 있게 저장
이 홈페이지를 처음 보는 손님 입장에서 검토해줘. 헷갈리는 부분, 빠진 정보, 틀린 정보가 있을 만한 곳 5가지를 알려줘.
QR 코드는 크롬에서 링크를 열고 공유 → QR 코드로 만들 수 있어요.
"손님 입장 검토" 프롬프트로 AI에게 셀프 점검을 시키되, 최종 확인은 사람. 링크를 반 단톡방에 공유해 서로 피드백하면 좋음. QR 메뉴 위치는 브라우저 버전에 따라 다름.
