🤔 남은 고민

Slack에서 대화는 정리됐는데, "그 주문 지금 어디까지 됐지?"는 여전히 스크롤해서 찾아야 합니다.

Slack = 대화하는 곳, Jira = 일의 상태를 보는 곳. 오늘은 두 번째를 만듭니다.
워크플로가 안 돈 수강생은 시간대·요일 설정을 바로 봐 주기(1~2분 이내). 과제로 가져온 "최근 주문 5건" 메모를 꺼내게 하기.

Jira = 주방의 주문 꽂이 8분

식당 주방을 떠올려 보세요. 주문서가 한 장씩 꽂이에 꽂히고, 요리가 진행되면 옆 칸으로 옮겨집니다. 누가 보든 어떤 주문이 어디쯤인지 한눈에 보이죠.
이슈 (Issue)
주문서 한 장. 해야 할 일 하나. 최근 화면에서는 작업 항목(Work item)으로 보일 수 있음
보드 (Board)
주문 꽂이 전체. 이슈 카드를 칸별로 늘어놓은 화면
상태 (Status)
꽂이의 칸. 접수 → 제작 중 → 배송 중 → 완료
담당자 (Assignee)
그 주문서를 지금 들고 있는 사람. 한 이슈에 한 명
새 용어 4개. Atlassian이 2025년부터 "이슈"를 "작업 항목(Work item)"으로 바꾸는 중이라 화면과 슬라이드 용어가 다를 수 있다고 미리 말하기. 수업에서는 짧은 "이슈"로 통일. 예상 질문: "엑셀로 하면 안 되나요?" → 4명이 동시에 고치고, 옮길 때마다 알림이 가고, 나중에 Slack·Claude와 연결되는 게 차이.

실습 1 · Jira Cloud 무료 가입 10분

  1. 크롬에서 atlassian.com → Jira → 무료로 시작(Get it free)
  2. Slack과 같은 회사 메일로 가입 → 메일 인증
  3. 사이트 이름 입력: 예) bomnal → 주소가 bomnal.atlassian.net이 됨
  4. 직무·팀 질문은 대충 고르거나 건너뛰기(Skip)
  5. 첫 화면(Jira 홈)이 보이면 성공 🎉 주소를 즐겨찾기
Free 플랜: 최대 10명, 저장 공간 2GB, 자동화 월 150 steps(10회차에서 계산). 봄날의 꽃 4명이면 충분합니다.
사이트 이름은 나중에 바꾸기 어렵습니다. 회사 영문 이름으로 짧게 정하세요.

요금·한도·가입 화면은 2026-10 기준이며 바뀔 수 있습니다. 수업 전 강사가 최신 화면을 확인하세요.

막히는 곳: 가입 중 "Confluence도 같이 쓰기" 같은 추가 제안 → 건너뛰기. 사이트 이름 중복 → 뒤에 숫자나 지역 붙이기(bomnal-mangwon).

실습 2 · 프로젝트 "봄날의 꽃 운영" 만들기 8분

  1. 왼쪽 메뉴 프로젝트(Projects) → 프로젝트 만들기(Create project)
  2. 템플릿에서 칸반(Kanban) 선택 → 템플릿 사용
  3. 유형은 팀 관리형(Team-managed) 선택 (설정이 쉬움)
  4. 이름: 봄날의 꽃 운영 / 키: BOM
  5. 만들기 → 보드 화면이 열리면 성공
키(BOM)는 주문서 번호의 앞글자입니다. 이슈가 BOM-1, BOM-2처럼 번호가 붙어요. 10·13회차 자동화가 이 키를 씁니다.
최근 화면에서는 "프로젝트"가 스페이스(Space)로 보일 수 있습니다. 같은 것입니다.
키는 자동으로 제안되니 BOM으로 직접 고쳐야 함. "회사 관리형(Company-managed)"을 고른 경우 설정 메뉴가 달라짐 → 새로 만드는 게 빠름.

실습 3 · 보드 칸을 우리 가게 순서로 바꾸기 7분

📥접수To Do
→
💐제작 중In Progress
→
🚚배송 중새로 추가
→
✅완료Done
  1. 보드에서 열 제목 To Do(할 일)에 마우스 → ⋯ → 이름 바꾸기 → "접수"
  2. In Progress → "제작 중", Done → "완료"
  3. 열 오른쪽 끝 + 버튼 → "배송 중" 추가 → 끌어서 제작 중과 완료 사이로
"완료" 열은 자동화 기준이 되니 이름을 정확히. 열 이름은 나중에 바꿔도 되지만 10회차 규칙을 만든 뒤에 바꾸면 규칙도 고쳐야 함.

실습 4 · 이슈 유형 만들기: 주문 · 문의 · 클레임 8분

  1. 왼쪽 아래 프로젝트 설정(Project settings) → 이슈 유형(Issue types)
  2. 이슈 유형 추가(Add issue type) → 이름 "주문", 아이콘 고르기
  3. 같은 방법으로 "문의", "클레임"
  4. "주문" 유형에 기한(Due date) 필드가 있는지 확인 → 없으면 오른쪽 필드 목록에서 끌어다 놓기
  5. 저장(Save changes)
유형예시누가 주로
주문꽃다발 M, 10/14 배송지수·유나·민호
문의"당일 배송 되나요?"대표
클레임배송 중 파손 → 사진 확인 후 재제작대표

화면에 따라 "작업 유형(Work type)"으로 보일 수 있습니다.

유형 이름은 13회차 봇(클레임/문의 이슈 자동 생성)과 같아야 하므로 정확히 "주문/문의/클레임". 기한(Due date) = 배송일로 쓰기로 약속.

강사 데모 · 주문 한 건의 하루 4분

👩‍💼10:20 접수대표가 BOM-12 만듦
→
💐11:00 제작 중담당: 지수
→
🚚14:30 배송 중담당: 민호
→
✅16:10 완료민호가 옮김
칸을 옮길 때 담당자도 같이 바꾸는 것이 핵심입니다. "지금 이 주문서를 들고 있는 사람"이 늘 보이게요.
10회차에서는 "완료" 칸으로 옮기면 Slack #주문에 자동으로 알림이 가게 만듭니다.
강사 보드에서 카드를 실제로 끌어 옮기며 시연. 카드를 클릭해 상세(설명·담당자·기한·댓글)도 보여 주기.

실습 5 · 주문 이슈 만들고 옮기기 10분

  1. 위쪽 + 만들기(Create) → 프로젝트 BOM, 유형 주문
  2. 요약: [주문] 꽃다발 M · 10/14 · 연남동
  3. 설명에 오른쪽 양식 붙여넣고 채우기
  4. 담당자: 지수 / 기한: 배송일 → 만들기
  5. 과제로 가져온 주문 5건도 같은 방법으로
  6. 보드에서 카드를 제작 중 → 배송 중 → 완료로 끌어 옮겨 보기
상품: 꽃다발 M (55,000원)
배송: 10/14 오후 / 서울 마포구 연남동 (배송비 무료)
받는 분: 김○○ 님
카드 문구: "생일 축하해"
결제: 스마트스토어 / 주문번호 끝 4자리 1234
전화번호·상세 주소·카드번호는 적지 마세요. 원본은 스마트스토어에 있습니다. 이 보드는 이후 Claude도 읽습니다.
주소는 "동"까지만, 받는 분은 성만. 배송 기사에게 필요한 상세 정보는 원래 채널(스마트스토어)에서 보도록 규칙화. 마포·서대문 무료, 그 외 5,000원(가게 설정) 확인.

실습 6 · Claude에게 이슈 만들기 맡기기 10분

  1. claude.ai → 설정(Settings) → 커넥터(Connectors) → Atlassian → 연결(Connect)
  2. Atlassian 로그인 → bomnal 사이트 선택 → 허용(Accept)
  3. 새 채팅에서 도구 메뉴에 Atlassian이 켜져 있는지 확인
  4. 오른쪽 프롬프트 실행 → Claude가 만들기 전에 묻는 내용 읽고 승인
  5. Jira 보드를 새로 고쳐서 5장이 생겼는지 확인
Jira BOM 프로젝트에 내일 배송할 "주문" 유형 이슈 5개를 만들어줘. 요약 형식: [주문] 상품 · 배송일 · 동네 기한: 내일 날짜, 상태: 접수, 담당자는 비워 둬. 1) 꽃다발 S · 망원동 2) 꽃다발 L · 합정동 3) 꽃바구니 · 서교동 4) 개업 화환 · 상암동 5) 꽃다발 M · 연희동 만들기 전에 표로 먼저 보여주고, 내가 "좋아"라고 하면 만들어줘.
AI가 만든 이슈는 한 장씩 확인하세요. 날짜·유형이 틀릴 수 있습니다. 지우는 일은 맡기지 마세요.

Atlassian 커넥터 이름·연결 화면은 2026-10 기준. 수업 전 확인.

"표로 먼저 보여 주고 승인 후 실행"은 AI에게 쓰기 권한을 줄 때의 기본 습관. 꼭 따라 하게 하기. 막히는 곳: 사이트를 고르는 단계에서 다른 Atlassian 사이트 선택, 이슈 유형 "주문"을 못 찾음(실습 4 미완료).

응용 실습 · 우리 회사 보드 설계하기 6분

나는 ○○(업종)을 운영하고 직원은 ○명이야. Jira 칸반 보드를 설계해줘. 1) 보드 칸(상태) 4~5개: 우리 일의 실제 순서대로 2) 이슈 유형 3개와 각각의 예시 3) 이슈 요약 작성 규칙 한 줄 (예: [유형] 내용 · 날짜 · 장소) 개인정보를 이슈에 적지 않는 규칙도 한 줄 넣어줘.
칸은 "누가 손에 들고 있나"가 바뀌는 지점에서 나누세요. 봄날의 꽃은 대표 → 플로리스트 → 배송 순서라 4칸입니다.
자기 회사 보드는 지금 만들 필요 없음. 설계표만 저장. 꽃집이 아닌 수강생(카페·공방 등) 예시를 하나 같이 풀어 주면 좋음.

자주 겪는 문제 4분

이럴 때이렇게
메뉴 이름이 슬라이드와 다르다이슈 = 작업 항목, 프로젝트 = 스페이스, 이슈 유형 = 작업 유형
"프로젝트 설정"에 이슈 유형 메뉴가 없다회사 관리형으로 만든 것. 팀 관리형으로 새로 만들기
만든 이슈가 보드에 안 보인다보드 위 필터 확인, 또는 이슈가 다른 프로젝트에 만들어졌는지 확인
Claude가 BOM 프로젝트를 못 찾는다커넥터에서 연결한 사이트 확인 → "BOM 프로젝트 목록 보여줘"로 테스트
Claude가 날짜를 틀리게 넣었다"오늘은 ○월 ○일이야"를 프롬프트에 함께 적기
자세한 대응은 materials/troubleshooting.html 참고.

🔜 10회차: Slack과 Jira 자동으로 잇기

#문의 메시지를 버튼 하나로 Jira 이슈로 만들고, 주문이 "완료"되면 Slack에 자동으로 알림이 가게 합니다.

팀원 초대: Jira 왼쪽 위 ⚙ 또는 사람 아이콘 → 사용자 초대. 무료는 10명까지. 다음 시간에 Slack 앱 설치를 하므로 관리자 권한 확인이 중요.
