왜 서버로 옮기나요? 6분

Make는 공유 주방을 빌려 쓰는 것, 서버는 우리 가게 주방입니다. 처음엔 빌려 쓰는 게 편하지만, 손님이 늘면 내 주방이 더 빠르고 싸고 마음대로 바꿀 수 있습니다.

Cloudflare Workers 무료 한도는 2026-10 기준이며 바뀔 수 있습니다.

"서버를 사야 하나요?" → 아니요. 서버 컴퓨터는 Cloudflare가 갖고 있고 우리는 코드만 맡김. 꺼질 걱정 없음. Make가 나쁜 게 아니라는 점: 월 문의 수십 건이면 Make로 충분. 이 비교표가 졸업 계획서의 "비용" 칸 재료가 됨. 오늘 새 용어 5개: 서버, Cloudflare Workers, 배포, 비밀값, 로그.

코드는 Claude Code에게 "명세"를 주고 받습니다 6분

명세 = 1회차의 좋은 요청 4요소를 프로그램용으로 쓴 것.

[상황] 꽃집 「봄날의 꽃」 LINE 공식계정용 AI 상담 봇 서버를 만들고 싶어. 나는 코딩을 모르니 파일마다 쉬운 한국어 설명을 달아줘. [할 일] Cloudflare Workers + TypeScript로 만들어줘. - POST /line/webhook: x-line-signature를 Channel secret으로 검사, 바로 200 응답 후 뒤에서 처리 - 손님 메시지의 전화·카드번호를 가린 뒤 Claude Haiku 4.5(claude-haiku-4-5)에 보내기 - 시스템 프롬프트 = 상담 규칙 + FAQ (첨부한 system-prompt.md) - 답은 JSON {answer, category, needs_human}. category: 영업정보|주문|배송|환불|불만|기타 - LINE에 reply token으로 답장. needs_human이면 Slack #cs-escalation 알림 + Jira BOM 이슈(클레임/문의) [조건] 비밀값은 코드에 쓰지 말고 환경변수: ANTHROPIC_API_KEY, LINE_CHANNEL_SECRET, LINE_CHANNEL_ACCESS_TOKEN, SLACK_WEBHOOK_URL, JIRA_BASE_URL, JIRA_EMAIL, JIRA_API_TOKEN, JIRA_PROJECT_KEY. 테스트도 만들어줘. [형식] 폴더 구조 + 파일 + 배포 방법 README
수업에서는 이 명세로 만든 완성본 examples/messenger-bot/을 씁니다. 사용법은 그 폴더의 README.md. 직접 Claude Code로 만들어 보는 방법은 부록 C.
강사가 Claude Code에 이 명세를 넣고 코드가 만들어지는 장면을 2~3분 보여 주면 효과 큼(미리 녹화해 둔 영상도 OK). 수강생은 직접 만들지 않음 — AI가 매번 조금씩 다른 코드를 만들어 수업 진행이 어려워지기 때문. 핵심 메시지: "코드를 읽을 줄 몰라도, 무엇을 원하는지 정확히 말하면 AI가 만든다. 단, 비밀값·보안 조건은 사람이 명세에 꼭 넣어야 한다."

실습 1 · 터미널 열고 Cloudflare 로그인 8분

  1. Node.js가 없으면 nodejs.org → LTS 다운로드 후 설치
  2. 교재 폴더를 받아 둔 곳에서 터미널 열기 (맥: 터미널 앱 / 윈도: PowerShell)
  3. 아래 명령을 한 줄씩 복사 → 붙여넣기 → Enter
  4. wrangler login을 치면 브라우저가 열림 → Cloudflare 로그인 → Allow(허용)
  5. 터미널에 Successfully logged in 이 보이면 성공
cd examples/messenger-bot
npm install
npx wrangler login
터미널은 마우스 대신 글자로 컴퓨터에 일을 시키는 창입니다. 오늘은 복사-붙여넣기만 합니다. (부록 C에서 더 자세히)
가장 많이 막히는 곳: ① cd 경로 — 교재 폴더 위치가 사람마다 다름. Finder/탐색기에서 messenger-bot 폴더를 터미널 창으로 끌어다 놓으면 경로가 입력됨(맥) ② npm 명령이 없다고 나옴 → Node.js 설치 후 터미널을 새로 열기 ③ 회사 PC 보안으로 설치 불가 → 개인 노트북 사용. 터미널은 1회차 이후 처음 보는 낯선 화면이므로 "빨간 글자가 나와도 컴퓨터가 망가지지 않는다"고 안심시키기. 터미널은 새 용어 카드로 만들지 않고 안내 상자로만 설명(오늘 용어 5개 한도).

한 줄 치면 Enter a secret value가 나옵니다 → 값 붙여넣기 → Enter (화면에 안 보이는 게 정상). 비밀값을 wrangler.toml·코드·카톡·화면 공유에 절대 노출하지 마세요.
처음 secret put을 하면 "bomnal-bot이라는 Worker가 없는데 새로 만들까요?"라고 물음 → y. Slack·Jira 비밀값이 없으면 봇은 답장은 하고 직원 연결만 건너뜀(README 참고) — 시간이 없으면 앞의 3개만 넣고 진행 가능. 화면 공유 중이면 강사는 값 붙여넣기 전에 공유를 잠시 멈출 것. 잘못 넣었으면 같은 명령을 다시 치면 덮어씀.
