  1. 결과를 읽고 "이건 우리 샵 같지 않아" 하는 줄은 고쳐 달라고 하기
  2. 완성본을 복사해 프로젝트 → Project knowledge(프로젝트 지식)에 '말투 가이드'로 저장
수강생이 가져온 게시물 하나를 받아 즉석에서 시연하면 몰입도가 높음(고객 얼굴·이름 없는지 확인 후). 프로젝트에 저장하면 이후 모든 채팅이 이 말투를 따른다는 점이 핵심 — 3회차와 연결. 게시물이 없는 경우: "차분하고 믿음직한 1:1 피부관리실" 같은 설명만으로도 가이드 생성 가능.

실습 2 · 예약 리마인드·이벤트 문자 만들기 10분

SMS · LMS
SMS는 짧은 문자(90바이트 = 한글 약 45자), 넘으면 LMS(장문 문자)로 바뀌고 건당 요금이 더 비쌉니다.
수신 동의한 회원님께 보낼 웨딩·여름 시즌 등 관리 이벤트 문자를 써줘. 등 관리(50분 60,000원) 첫 회 10% 할인, 5/1~5/31, 네이버 예약으로 예약, 홍대입구역 3번 출구 도보 5분. ① SMS용: 공백 포함 한글 45자 이내 3개 ② LMS용: 300자 이내 1개 맨 앞에 (광고), 맨 끝에 '무료수신거부 080-000-0000'을 넣어줘. 각 문안의 글자 수도 세어줘.
노쇼를 줄이려고 예약 전날 보내는 리마인드 문자를 SMS 길이로 써줘. 넣을 것: 내일 예약 시간, 관리 메뉴 자리 [ ], 24시간 이내 취소 시 예약금 환불 불가, 10분 이상 지각 시 관리 시간 단축 가능. 부드럽게.
리마인드 문자는 예약 안내라 광고가 아니지만, 할인·이벤트 문구를 섞으면 광고가 됩니다. 광고 문자는 (광고) 표시 · 수신거부 방법 · 수신 동의한 고객에게만, 밤 9시~아침 8시 발송은 별도 동의가 필요합니다(정보통신망법). 080 번호는 예시이니 실제 번호로 바꾸세요.

글자 수는 AI가 자주 틀립니다. 문자 발송 화면의 바이트 표시로 최종 확인하세요. 2026-10 기준.

리마인드 문자는 4회차에서 본 "노쇼 4건이 모두 저녁 예약" 결과와 연결 — 숫자를 보고 대책을 만드는 흐름. 리마인드·광고 구분 기준은 수업 전 KISA 안내로 확인. "90자"가 아니라 "90바이트"라는 점이 자주 헷갈림. 한글 1자 = 2바이트, 영문·숫자·공백 1바이트. (광고)·수신거부 문구가 들어가면 SMS 길이가 매우 빠듯함 → 그래서 LMS를 쓰는 가게가 많다는 현실도 공유. 할인율·기간은 예시 — 실제 이벤트 가격은 원장이 정하고 AI는 지어내지 않게. 법 세부는 수업 전 최신 KISA 안내 확인. 개인정보: 고객 전화번호 목록은 Claude에 넣지 않는다.

말투 가이드를 따라 두 리뷰에 각각 답글을 써줘. 100자 이내. 나쁜 리뷰는 사과 → 대기 원인 확인 약속 → 피부 상태는 원장이 직접 연락드려 확인 순서로. 환불·보상·할인은 약속하지 말고, "부작용", "정상 반응이에요" 같은 판단도 하지 마.
리뷰에 고객 이름·예약번호가 있으면 지우고 붙여넣으세요. 관리 후 트러블 호소는 원장이 직접 연락해 확인하고, 보상도 원장이 판단합니다. 공개 답글에 고객 피부 상태를 자세히 적지 마세요.
"환불·보상은 AI가 약속하지 않는다", "트러블 호소는 사람에게"는 13회차 상담봇 규칙과 같음(category 불만 + 사람 연결). 2회차 수칙에 이미 들어 있는지 확인. 나쁜 리뷰 답글은 3가지 버전을 받아 고르는 게 좋음. 감정적인 답글을 일부러 요청해 보면 왜 검토가 필요한지 체감.

응용 실습 · 우리 회사 1주치 홍보 세트 10분

  1. 내 회사(또는 봄날 에스테틱) 말투 가이드에 "안 쓰는 말"까지 넣어 저장했는지 확인
  2. 다음 주 인스타 캘린더 만들기 — 지난달 매출 1위 관리(상품)를 주인공으로
  3. 시즌 이벤트 문자 1개(SMS 또는 LMS) 만들고 글자 수·의료 표현 확인
  4. 마음에 안 드는 칸은 "수요일만 다시, 더 짧게"처럼 부분만 고치기
  5. 완성본을 저장하고, 실제로 이번 주에 1개 올려 보기
돌아다니며 확인: 없는 할인·없는 수상 경력 같은 지어낸 사실, "치료·재생" 같은 의료 표현, 광고 문자 필수 문구. 잘 된 캘린더 1개를 화면 공유하고 반 전체가 피드백.

자주 겪는 문제 5분

이럴 때이렇게
글이 다 비슷비슷하고 뻔하다"3가지 다른 버전으로", "관리사 시점으로" 등 각도를 바꿔 요청
말투 가이드를 안 따른다프로젝트 안 채팅인지 확인, "말투 가이드 ③번을 지켜서"처럼 콕 집기
문자 글자 수가 넘친다발송 화면에서 바이트 확인 후 "5자 더 줄여줘"
"이미지를 그려 달라"고 했더니 그림이 안 나온다정상입니다. 이미지 프롬프트를 받아 캔바 등에서 생성
고쳐도 "개선", "재생" 같은 말이 계속 나온다말투 가이드 "안 쓰는 말"에 단어를 콕 집어 적고, "금지어 목록을 지켰는지 마지막에 점검해줘"라고 덧붙이기
해시태그가 엉뚱하다우리 샵이 실제 쓰는 해시태그 5개(#연남동피부관리 등)를 말투 가이드에 적어 두기
자세한 대응은 materials/troubleshooting.html. 해시태그 효과에 대한 질문은 "정답 없음, 일관성이 중요"로 짧게.

오늘의 체크리스트 ✅ 3분

한 일을 눌러서 체크하세요. (이 컴퓨터에 저장됩니다)

  • 우리 샵 말투 가이드를 만들어 프로젝트에 저장했다
  • 의료·과장 표현을 걸러 내고 인스타 1주 콘텐츠 캘린더(표)를 만들었다
  • 예약 리마인드 문자와 이벤트 문자를 만들고 (광고)·수신거부 문구와 길이를 확인했다
  • 일본어 공지를 되돌려 번역해 확인했다
  • Claude는 그림을 직접 그리지 않는다는 걸 알고, 이미지 프롬프트를 받아 봤다
체크 못 한 항목은 과제로. 다음 시간 시작 5분에 캘린더와 문자 확인.

🔜 6회차: 샵 홈페이지 만들기

코딩 없이 Claude에게 말로 부탁해서 메뉴·가격·위치·예약 버튼이 있는 1페이지 소개 사이트를 만들고, 링크로 고객에게 공유합니다.

링크 모아 오기 과제가 6회차 진행 속도를 좌우함. 특히 네이버 예약 링크는 예약 버튼에 바로 쓰임. 단톡방에 "링크 복사하는 법"(앱의 공유 버튼 → 링크 복사)을 함께 올려 두기.
