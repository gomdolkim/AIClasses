수업 전 준비 · 계정 체크리스트

한꺼번에 준비하지 마세요. 필요한 회차 전까지만 하나씩 준비하면 됩니다. 항목을 누르면 체크되고, 이 브라우저에 저장됩니다.

가입은 모두 같은 회사 대표 메일로 하세요. 나중에 서비스끼리 연결할 때 훨씬 편합니다.

회차별: 언제까지 무엇을

1회차 전 처음

  • PC(노트북)와 크롬(Chrome) 브라우저 설치
  • 문자를 받을 수 있는 휴대폰
  • 회사 대표 메일 주소(또는 개인 Gmail) 비밀번호 확인

3회차 전 Claude Pro

  • Claude Pro 결제 (월 $20) — claude.ai → Settings(설정) → Billing(결제)
  • 해외 결제 가능한 카드 준비
  • 1회차 과제: 우리 회사 자주 묻는 질문 10개 적기
  • 실습 데이터 내려받기: faq.md, price-list.md, brand-voice.md, reservations-sample.csv, tricky-questions.md

6회차 전 홈페이지 재료

  • 네이버 예약(스마트플레이스) 예약 페이지 링크 복사해 두기
  • LINE 공식계정 친구 추가 링크(있으면) 복사해 두기
  • 샵 내부·관리실 사진 3장 — 손님 얼굴·전후 사진은 동의서 받은 것만

8회차 전 Slack Pro

  • Slack 워크스페이스 만들기 (또는 강사 워크스페이스 초대 수락)
  • Slack Pro 결제 (1인당 월 $8.75, 연간 결제 시 $7.25) — 강사 안내에 따라
  • PC용 Slack 앱과 휴대폰 앱 설치
  • MCP 연결 준비: Slack 워크스페이스 관리자(소유자)가 Claude 앱·커넥터(MCP 연결)를 승인 — 원장님이 소유자면 본인이 승인, 수업용 워크스페이스는 강사가 승인 (부록 F, 관리자 화면 메뉴 위치는 수업 전 확인)

9회차 전 Jira

  • Atlassian 계정 만들고 Jira Free 사이트 만들기 (무료, 10명까지)
  • 사이트 주소 메모해 두기 (예: ○○.atlassian.net)
  • MCP 연결 준비: 내 계정이 사이트 관리자(조직 관리자)인지 확인 — Claude에 Jira를 처음 연결하는 사람은 관리자가 안전
  • Atlassian Administration → Rovo → Rovo MCP server에서 "Allow Atlassian supported domains"가 켜져 있는지 확인 (꺼져 있으면 claude.ai 연결이 막힘, 기본값은 수업 전 확인)

12회차 전 LINE 공식계정

  • 휴대폰에 LINE 앱 설치·가입
  • LINE 공식계정 만들기 (무료 플랜) — LINE Official Account Manager
  • 테스트용으로 내 LINE에서 공식계정 친구 추가

13회차 전 Make

  • Make 무료 계정 만들기 (월 1,000 credits)
  • Anthropic Console 가입 + 소액 크레딧 충전 + 지출 한도(Spend limit) 설정
  • API 키 발급 → 비밀번호 관리자나 안전한 메모에만 보관

14회차 전 봇 서버

  • LINE Developers 콘솔 로그인 → 공식계정에 Messaging API 켜기
  • Cloudflare 무료 계정 만들기
  • Node.js LTS 설치 → 터미널에서 node -v 확인
  • 졸업 발표 준비: 우리 회사 AI 도입 계획서 초안

강사 사전 테스트 (8회차 전) 강사용 · MCP

  • Pro 개인 계정에서 Customize → Connectors → Discover로 Slack(Slack 공식, Verified) 커넥터가 연결되는지 실기 확인 — 공식 문서끼리 설명이 달라 수업 전 확인 필수
  • Slack Free 워크스페이스에서도 MCP 연결이 되는지 확인 (공식 명시 없음)
  • Atlassian 커넥터 연결 → BOM 프로젝트 이슈 읽기·만들기 테스트, 화면(허용 화면·사이트 선택) 캡처
  • 도구 권한을 읽기 Always allow / 쓰기 Needs approval / 삭제 Blocked로 맞춰 두고 승인 창이 뜨는지 확인
  • 한국어 UI 메뉴 이름(“사용자 지정”, “커넥터”)과 모바일 앱에서 커넥터 사용 가능 여부 확인

보안 수칙 요약

✅ 이렇게 하세요

  • API 키·토큰·Webhook URL은 비밀번호처럼 보관
  • 비밀값은 코드가 아닌 환경변수(wrangler secret put, Make 연결)에만
  • Anthropic Console에 지출 한도 설정
  • 봇 첫 인사에 "AI 상담원"임을 알리기 (AI 기본법, 2026-01-22 시행)
  • 어려운 문의는 사람에게 넘기기 (#cs-escalation)

⛔ 하지 마세요

  • 손님 전화번호·카드번호·주소를 프롬프트에 그대로 넣기
  • 손님 피부 상태·질환·임신 여부를 실명과 함께 AI에 넣기 (건강 관련 민감정보)
  • 전후 사진을 동의 없이 AI·SNS에 올리기
  • 비밀값을 단톡방·화면 공유·캡처·GitHub에 올리기
  • AI가 환불·보상·할인을 약속하게 두기
  • AI 답변을 확인 없이 손님에게 보내기 (특히 가격·예약 날짜·성분 효능)
  • 퇴사한 직원 계정을 그대로 두기
비밀값이 노출됐다면 즉시 폐기·재발급하세요. 순서는 문제 해결 카드 → 비밀값 유출에 있습니다.
