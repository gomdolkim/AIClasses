커넥터 (Connector) 8회차

Claude를 Slack·Jira 같은 서비스와 잇는 MCP 연결 하나하나. Customize(사용자 지정) › Connectors(커넥터)에서 추가하고, 대화마다 입력창 + › Connectors에서 켜고 끕니다 (부록 F)

비유만능 콘센트(MCP)에 꽂는 서비스별 플러그 — 또는 비서에게 발급한 다른 사무실 출입증

OAuth (허용 화면) 8회차

비밀번호를 Claude에 알려 주지 않고, Slack·Atlassian 로그인 화면에서 "이 앱이 이런 일을 해도 될까요?"를 확인하고 허용을 눌러 권한만 빌려 주는 방식. 내 계정이 볼 수 있는 범위까지만 열립니다

비유건물 관리실에서 방문증을 받는 것 — 열쇠(비밀번호)는 내가 갖고, 방문증은 언제든 회수(Disconnect)할 수 있음

도구 권한 (Always allow · Needs approval · Blocked) 8회차

커넥터의 도구(읽기·보내기·만들기 등)마다 정하는 사용 규칙. Always allow=묻지 않고 사용, Needs approval=매번 내가 확인, Blocked=사용 금지. 권장: 읽기는 Always allow, 보내기·만들기·수정은 Needs approval, 삭제·관리는 Blocked (부록 F)

비유신입 관리사 업무 범위 — 예약표 보기는 자유, 손님에게 문자 보내기는 실장 확인 후, 환불 처리는 금지
