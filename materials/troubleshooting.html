🔐 로그인 · 결제 1·3회차

증상이렇게 해 보세요
인증 문자가 안 와요번호를 국가코드 +82로 선택했는지 확인 → 1~2분 뒤 재전송. 같은 번호로 여러 번 시도하면 잠시 막히니 10분 쉬었다가.
인증 메일이 안 와요스팸함·프로모션함 확인. 회사 메일이면 보안 필터에 막혔을 수 있으니 개인 Gmail로 시도.
로그인이 계속 풀려요처음 가입한 방법(Google로 계속하기 / 이메일)과 같은 방법으로 로그인. 시크릿 창이면 일반 창으로.
카드 결제가 거절돼요해외 결제 가능 카드인지 확인(달러 결제). 카드사 앱에서 해외 온라인 결제 차단을 해제.
결제했는데 Pro가 안 보여요로그아웃 후 다시 로그인. 결제한 계정과 지금 계정(메일)이 같은지 확인.

🤖 Claude 한도 · 커넥터 2·3·11회차

증상이렇게 해 보세요
"사용량 한도에 도달했습니다"표시된 시간이 지나면 다시 쓸 수 있습니다. 긴 파일·긴 대화가 한도를 빨리 씁니다 → 새 채팅으로 시작하고, 파일은 필요한 부분만 올리기.
답이 점점 이상해져요대화가 너무 길어진 것. 지금까지 결과를 요약해 달라고 한 뒤 새 채팅에 붙여넣고 이어서.
프로젝트 메뉴가 없어요무료 플랜이면 제한이 있습니다. Pro 결제 여부 확인. 왼쪽 메뉴의 Projects(프로젝트).
커넥터 연결이 안 돼요Settings(설정) → Connectors(커넥터)에서 해당 서비스 연결 해제 후 다시 연결. 팝업 차단을 끄고, 로그인 창에서 Claude와 같은 회사 계정을 선택. 무료 플랜은 커스텀 커넥터 1개만 됩니다.
AI가 "여드름 치료", "주름 제거 보장" 같은 표현을 써요에스테틱 홍보에는 의료·과장 표현을 쓰면 안 됩니다. 프로젝트 지침에 "치료·완치·시술·재생·효과 보장 표현 금지, 피부 상태는 진단하지 않기"를 넣고, 결과물마다 광고 표현 점검 카드로 한 번 더 걸러 주세요. (최신 규정은 수업 전 확인)
커넥터는 연결됐는데 "찾을 수 없음"그 서비스에서 내 계정에 권한이 있는지 확인(예: Jira 프로젝트 BOM 멤버인지). 대화창의 도구 아이콘에서 커넥터가 켜져 있는지 확인.

💬 Slack 권한 · 앱 승인 8·10회차

증상이렇게 해 보세요
Workflow Builder(워크플로 빌더)가 없어요무료 플랜은 사용이 제한될 수 있습니다(수업 전 확인). Pro 이상인지, 관리자가 워크플로 사용을 막지 않았는지 확인.
앱 설치가 "승인 요청"으로만 돼요워크스페이스가 앱 승인제입니다. 관리자(Owner/Admin)가 앱 관리 → 요청에서 승인해야 합니다. 수업용 워크스페이스는 강사가 미리 승인.
무료 플랜에서 앱을 더 못 깔아요무료 플랜은 앱 10개까지. 안 쓰는 앱을 제거하거나 Pro로.
봇 메시지가 채널에 안 와요앱(봇)을 그 채널에 초대했는지 확인: 채널에서 /invite @앱이름. 비공개 채널은 꼭 초대가 필요합니다.
Incoming Webhook URL을 단톡방에 올렸어요URL은 비밀번호입니다. 앱 설정에서 해당 Webhook을 삭제하고 새로 만드세요. (비밀값 유출 대응)

📋 Jira 권한 · Automation 한도 9·10·11회차

증상이렇게 해 보세요
프로젝트가 안 보여요사이트 관리자가 나를 초대했는지, 프로젝트 BOM의 접근 권한에 내가 있는지 확인. Free는 사용자 10명까지.
이슈 유형에 "예약"이 없어요프로젝트 설정 → 이슈 유형(작업 유형)에서 예약·문의·클레임 3개를 추가. 보드 열은 접수 → 예약 확정 → 관리 완료 → 사후 연락 완료 순서인지 확인.
이슈를 못 옮겨요(권한 없음)프로젝트 설정의 권한/역할에서 내 역할이 "멤버" 이상인지 확인.
Slack에서 "Create issue"가 안 보여요"Jira Cloud for Slack" 앱 설치·로그인 확인. 메시지 ⋯ 메뉴 → 더 보기 → Create issue.
자동화 규칙이 갑자기 멈췄어요Automation 월 한도 초과 가능성. Free는 사이트 전체 월 150 steps(트리거·조건·액션 각 1 step), 한도에 닿으면 다음 달까지 정지. Automation → 사용량에서 확인하고, 테스트 반복을 줄이세요.
규칙은 실행됐는데 Slack 알림이 없어요규칙의 감사 로그(Audit log)에서 실패 단계 확인. Slack 액션의 Webhook URL·채널을 다시 확인.

🧩 Make 시나리오 오류 · credits 13회차

증상이렇게 해 보세요
모듈에 빨간 느낌표그 모듈을 눌러 오류 메시지 확인. 대부분 연결(Connection) 만료 → 다시 연결. 매핑한 값이 비어 있지 않은지 확인.
"Run once"는 되는데 실제로는 안 돌아요시나리오 아래 스위치가 ON인지, 스케줄이 "즉시(Immediately)"인지 확인. 무료는 활성 시나리오 2개까지.
credits가 금방 바닥나요Free는 월 1,000 credits. 모듈 하나 실행마다 소모됩니다. 테스트를 짧게 하고, 필요 없는 모듈·반복을 줄이세요. 부족하면 Core($9) 고려.
Claude 모듈 401/인증 오류Anthropic API 키가 틀리거나 폐기됨. Console에서 새 키 발급 후 Make 연결을 다시 만드세요. 결제 크레딧 잔액도 확인.
JSON 파싱 오류Claude가 JSON 밖에 설명을 붙인 경우. 시스템 프롬프트에 "JSON만 출력"을 다시 강조하고, 예시 JSON을 넣어 주세요.

🟢 LINE 12·13·14회차

증상이렇게 해 보세요
Webhook "검증(Verify)" 실패URL이 https://로 시작하고 끝 경로(/line/webhook)까지 정확한지 확인. 서버(Make 시나리오/Worker)가 켜져 있고 200 응답을 바로 돌려주는지 확인. 서명 검증에 쓰는 Channel secret이 맞는지 확인.
메시지를 보내도 봇이 응답 없음LINE Developers 콘솔에서 Use webhook(Webhook 사용)이 켜져 있는지 확인. Channel access token이 맞는지, reply token을 1분 안에 한 번만 썼는지 확인. 서버 로그에서 오류 확인.
답장이 두 번 와요(중복)LINE Official Account Manager의 응답 메시지(応答メッセージ)를 OFF로 하세요. 자동응답과 봇이 동시에 답하고 있는 것입니다. 인사말(あいさつメッセージ)도 봇과 겹치지 않게 정리.
봇이 "예약 확정됐습니다"라고 답해요봇은 예약을 확정할 수 없습니다. 시스템 프롬프트에 "예약은 네이버 예약 링크로 안내하고, 날짜·시간을 확정한다고 말하지 않는다"를 넣고, 짓궂은 질문(tricky-questions.md)으로 다시 시험하세요.
무료 메시지가 다 떨어졌대요무료 플랜은 월 200통(보내는 홍보 메시지 기준). Reply API·응답 메시지는 통수에 포함되지 않습니다. 예약 리마인드·이벤트 단체 발송을 줄이거나 라이트(5,000엔) 고려.
일본어 메뉴라 못 찾겠어요설정(設定) → 응답 설정(応答設定) 순서. 브라우저 번역 기능을 켜도 됩니다.

☁️ wrangler · 배포 14회차

증상이렇게 해 보세요
npx: command not foundNode.js가 설치되지 않았거나 터미널을 새로 열지 않았습니다. Node.js LTS 설치 후 터미널을 닫았다 다시 열기. node -v로 확인.
로그인 창이 안 떠요 / "Not authenticated"npx wrangler login 실행 → 브라우저에서 Cloudflare 로그인 후 허용(Allow).
배포는 됐는데 500 오류비밀값이 빠졌을 가능성. npx wrangler secret put ANTHROPIC_API_KEY처럼 8개 비밀값을 모두 넣었는지 확인. 로그는 npx wrangler tail.
401 / 서명 불일치LINE_CHANNEL_SECRET 값이 틀렸거나 앞뒤 공백이 들어감. 다시 secret put.
Jira 이슈가 안 만들어져요JIRA_BASE_URL(https://○○.atlassian.net), JIRA_EMAIL, JIRA_API_TOKEN, JIRA_PROJECT_KEY(=BOM) 확인. 이슈 유형 이름(클레임/문의)이 프로젝트에 있는지 확인.

⛔ 비밀값이 유출됐을 때 언제나

API 키, 토큰, Channel secret, Webhook URL이 단톡방·화면 공유·녹화·GitHub·캡처에 노출됐다면 "아무도 안 봤겠지"라고 생각하지 마세요. 즉시 폐기하고 재발급합니다.
  1. 즉시 폐기: 해당 서비스 관리 화면에서 그 키를 삭제(Revoke)하거나 재발급(Reissue)합니다. Anthropic Console·LINE Developers·Slack 앱 설정·Atlassian 계정 보안 화면.
  2. 새 값 넣기: 새 키를 Make 연결 또는 npx wrangler secret put 이름으로 다시 넣습니다.
  3. 흔적 지우기: 올린 메시지·캡처·파일을 삭제합니다. (삭제만으로는 부족 — 반드시 1번 먼저)
  4. 사용량 확인: Anthropic Console 사용량, 결제 내역에 모르는 사용이 있는지 확인합니다. 지출 한도(Spend limit)를 낮게 설정해 두세요.
  5. 기록: 언제·무엇이·어디에 노출됐는지 강사(또는 대표)에게 알립니다.
