1. 대상과 목표

누가 듣나요?

  • IT·AI를 전혀 모르는 성인
  • 2~10명 규모의 작은 회사를 운영 중이거나 준비 중
  • 동기: 시간 절약과 매출
  • Claude Pro, Slack Pro 정도는 결제할 수 있음

과정을 마치면

  • Claude를 회사 비서로 매일 쓴다 (프로젝트·스킬)
  • Slack·Jira로 팀 업무를 정리하고 자동으로 잇는다
  • LINE AI 상담봇을 만들고 어려운 문의는 사람에게 넘긴다
  • 내 회사 AI 도입 계획서를 발표한다
모든 실습은 가상 회사 「봄날의 꽃」(망원동 꽃집, 직원 4명)으로 먼저 하고, 응용 실습에서 수강생 자기 회사로 바꿉니다. 회사 설정 숫자는 바꾸지 마세요 — 데이터셋·봇 예제와 맞물려 있습니다.

3. 회차별 운영 팁

1회차 · AI 비서 첫 출근
문자 인증이 가장 많이 막힙니다. 짝 실습으로 진행하고, Pro 결제는 과제로 넘기세요. FAQ 10개 과제가 3·12·13회차 재료입니다.
2회차 · 잘하는 일, 틀리는 일
일부러 틀리는 질문(“망원동 꽃집 매출 1위는?”)으로 할루시네이션을 직접 겪게 하세요. 개인정보 마스킹 연습을 꼭 넣습니다.
3회차 · 프로젝트 & 스킬
Pro 미결제자는 짝의 화면을 함께 봅니다. dataset 폴더의 faq.md·price-list.md·brand-voice.md를 미리 내려받게 하세요.
4회차 · 문서·엑셀
orders-sample.csv의 합계를 Claude가 계산하면 반드시 엑셀로 한 번 검산하게 합니다(숫자 검증 습관).
5회차 · 마케팅
“우리 말투” 비교가 핵심. brand-voice.md 적용 전/후를 나란히 보여 주세요.
6회차 · 홈페이지
아티팩트 공유 링크는 누구나 볼 수 있으니 개인 전화번호를 넣지 않게 합니다. 인터넷 주소 연결은 부록 A로 안내.
7회차 · API와 웹훅
코딩 없는 회차입니다. “식당 주문서(API)”와 “초인종(웹훅)” 비유로 그림만 그립니다. 8~14회차의 기초라 서두르지 마세요.
8회차 · Slack
강사가 만든 실습 워크스페이스에 초대하는 방식이 가장 빠릅니다. Workflow Builder 사용 가능 플랜을 수업 전에 확인하세요.
9회차 · Jira
프로젝트 이름 “봄날의 꽃 운영”, 키 BOM, 열 4개(접수→제작 중→배송 중→완료)를 그대로 맞추게 하세요. 이후 회차 예제가 이 이름을 씁니다.
10회차 · Slack↔Jira
Jira Free Automation은 사이트 전체 월 150 steps입니다. 수강생이 같은 사이트를 공유하면 한도가 금방 찹니다 → 각자 사이트 권장.
11회차 · AI 주간 보고
Jira에 이슈가 적으면 보고서가 빈약합니다. 수업 전 샘플 이슈 10~15개를 만들어 두게 하세요.
12회차 · LINE 자동응답
일본어 계정 화면이 섞여 나옵니다. 메뉴명을 일본어·한국어로 병기한 화면 캡처를 미리 준비하세요.
13회차 · Make 상담봇
API 키를 화면 공유 중에 노출하지 않도록 주의. Make 무료 credits가 테스트 반복으로 빨리 줄어듭니다.
14회차 · 봇 서버 & 졸업
배포는 앞 45분, 발표는 뒤 45분으로 시간을 엄격히 나눕니다. 배포에 실패해도 13회차 Make 봇으로 발표할 수 있게 하세요.

4. 수업 전 강사 준비

계정 · 환경

  • 강사용 Claude Pro 계정 (데모 전용, 개인 대화 기록 없는 것)
  • 실습용 Slack 워크스페이스 + 채널 #공지 #주문 #문의 #스탠드업 #cs-escalation
  • 강사용 Jira 사이트 + 프로젝트 “봄날의 꽃 운영”(BOM)
  • 테스트용 LINE 공식계정 + 친구 추가한 테스트 폰(또는 두 번째 LINE 계정)
  • Make 계정 + 13회차 완성본 시나리오
  • Cloudflare 계정 + examples/messenger-bot/ 배포 확인
  • Anthropic Console 계정 + 사용 한도(Spend limit) 설정

교실 · 자료

  • 빔프로젝터 해상도 확인, 브라우저 확대 125~150%
  • 강의 슬라이드를 미리 열고 N으로 노트 확인
  • dataset 파일 공유 링크(단톡방 등) 준비
  • 바뀐 화면·요금이 있는지 실제 서비스에서 확인
  • Wi-Fi 비밀번호와 휴대폰 문자 인증 가능 여부 안내
  • 문제 해결 카드(troubleshooting) 탭 열어 두기
강사 화면에서 API 키·Webhook URL·토큰이 보이면 그 즉시 폐기하고 재발급하세요. 녹화 영상에 남은 비밀값도 유출로 봅니다.

5. 표준 90분 진행 순서

순서내용시간
① 표지 · 오늘의 목표목표 1문장 + 결과물 1개 제시5분
② 지난 시간 결과물 확인2~3명 화면 공유 (2회차부터)5분
③ 비유로 개념 잡기새 용어는 5개 이하, 비유 먼저10분
④ 강사 데모완성된 모습을 먼저 보여 주기10분
⑤ 따라 하기 실습봄날의 꽃으로 단계별 진행25분
⑥ 응용 실습우리 회사에 적용20분
⑦ 자주 겪는 문제 · 체크리스트막힌 사람 정리10분
⑧ 과제 & 다음 예고다음 회차 준비물 안내5분

실습이 밀리면 ⑥ 응용 실습을 과제로 넘기고, ⑤까지는 반드시 끝내세요. 결과물을 손에 쥐고 가는 것이 우선입니다.

6. 강사 노트 보는 법

모든 슬라이드 아래에 강사 노트(시간 배분, 막히는 지점, 예상 질문)가 숨어 있습니다.

  1. 슬라이드에서 키보드 N을 누르거나 상단 바의 🎤 버튼을 누르면 노트가 보였다 숨었다 합니다.
  2. 주소 끝에 ?notes=1을 붙이면 처음부터 노트가 켜진 채로 열립니다. 예: lessons/01-ai-first-day.html?notes=1
  3. 노트 켜짐 상태는 그 브라우저에 기억됩니다. 수강생에게 화면을 넘기기 전 꼭 끄세요.
노트북은 노트를 켠 창, 빔프로젝터는 노트를 끈 창(다른 브라우저 또는 시크릿 창)으로 두 개를 띄우면 편합니다.

7. PDF로 인쇄하기

  1. 크롬에서 강의 슬라이드를 엽니다. (강사용 PDF가 필요하면 먼저 N으로 노트를 켭니다)
  2. Ctrl+P (맥은 ⌘+P)
  3. 대상: PDF로 저장 · 레이아웃: 가로 · 더보기 → 배경 그래픽 체크
  4. 저장 → 슬라이드 1장이 PDF 1쪽으로 나옵니다.

이 페이지 같은 자료 페이지도 같은 방법으로 인쇄됩니다(세로 권장).

8. 평가

회차별 결과물 포트폴리오

수강생은 매 회차 결과물 1개를 하나의 폴더(또는 Claude 프로젝트, Slack 채널 등)에 모읍니다. 14개 중 10개 이상 제출 시 수료를 권장합니다. 결과물 목록은 시간표의 “결과물” 열과 같습니다.

졸업 발표 루브릭 (14회차, 1인 5분)

항목3점 (훌륭)2점 (좋음)1점 (보완)
문제 정의우리 회사 반복 업무를 숫자(시간·건수)로 설명문제는 분명하나 숫자 없음문제가 막연함
AI·자동화 적용과정에서 배운 도구 2개 이상을 연결해 시연도구 1개로 시연계획만 있음
안전·개인정보개인정보·비밀값·AI 고지·사람 연결을 모두 고려일부 고려언급 없음
실행 계획다음 1개월 할 일·비용·담당자가 구체적할 일만 있음계획 없음
전달력비전문가도 이해하는 말과 화면대체로 이해됨용어가 어렵거나 시간 초과

15점 만점. 점수보다 “다음 달에 실제로 쓸 것 1개”를 정하게 하는 것이 목적입니다.

9. 수강생이 막힐 때

현장 원칙

  • 3분 규칙: 3분 넘게 막히면 손을 들게 하고, 짝의 화면으로 계속 따라가게 합니다.
  • 같은 문제가 2명 이상이면 전체를 멈추고 화면으로 함께 해결합니다.
  • 계정·결제 문제는 수업 중에 붙잡지 말고 쉬는 시간·과제로 넘깁니다.
  • “에러 메시지 화면을 Claude에 그대로 보여 주고 물어보기”를 습관으로 만들어 줍니다.

바로 쓰는 자료

  • 문제 해결 카드 — 증상별 대처
  • 누적 용어집 — 용어를 잊었을 때
  • 프롬프트 카드 — 무엇을 물어야 할지 모를 때
  • 준비 체크리스트 — 계정이 없을 때
지금 [서비스 이름]에서 [하려던 일]을 하다가 아래 화면이 나왔어. 컴퓨터를 잘 모르는 사람도 따라 할 수 있게, 무엇이 문제인지와 해결 순서를 3단계 이내로 알려줘. (화면 캡처 첨부)
