1. 대상과 목표

누가 듣나요?

  • IT·AI를 전혀 모르는 성인
  • 2~10명 규모의 작은 회사를 운영 중이거나 준비 중
  • 동기: 시간 절약과 매출
  • Claude Pro, Slack Pro 정도는 결제할 수 있음

과정을 마치면

  • Claude를 회사 비서로 매일 쓴다 (프로젝트·스킬)
  • Slack·Jira로 팀 업무를 정리하고 자동으로 잇는다
  • LINE AI 상담봇을 만들고 어려운 문의는 사람에게 넘긴다
  • 내 회사 AI 도입 계획서를 발표한다
모든 실습은 가상 회사 「봄날 에스테틱」(연남동 피부관리 샵, 직원 4명)으로 먼저 하고, 응용 실습에서 수강생 자기 회사로 바꿉니다. 회사 설정 숫자는 바꾸지 마세요 — 데이터셋·봇 예제와 맞물려 있습니다.
수강생이 실제 샵 원장님이면 실제 고객 차트·전후 사진을 올려 보고 싶어 합니다. 피부 상태·질환·임신 여부는 건강 관련 민감정보입니다. 수업에서는 dataset의 가상 데이터만 쓰고, 실제 데이터는 이니셜·마스킹 원칙(2회차)을 지킨 뒤에만 쓰게 하세요.

3. 회차별 운영 팁

1회차 · AI 비서 첫 출근
문자 인증이 가장 많이 막힙니다. 짝 실습으로 진행하고, Pro 결제는 과제로 넘기세요. FAQ 10개 과제가 3·12·13회차 재료입니다.
2회차 · 잘하는 일, 틀리는 일
일부러 틀리는 질문(“연남동 에스테틱 매출 1위는?”, “이 성분이 여드름을 치료하나요?”)으로 할루시네이션을 직접 겪게 하세요. 피부 상태·질환·임신 여부는 민감정보라 실명과 함께 넣지 않는 마스킹 연습, 전후 사진 동의 이야기를 꼭 넣습니다.
3회차 · 프로젝트 & 스킬
Pro 미결제자는 짝의 화면을 함께 봅니다. dataset 폴더의 faq.md·price-list.md·brand-voice.md를 미리 내려받게 하세요. 원장님 수강생은 실제 고객 차트를 올리고 싶어 하니 “가상 데이터로만”을 먼저 못 박으세요.
4회차 · 문서·엑셀
reservations-sample.csv로 노쇼율·재방문율·메뉴별 매출을 Claude가 계산하면 반드시 엑셀로 한 번 검산하게 합니다(숫자 검증 습관). 기준값: 50건 중 완료 40·노쇼 4·취소 4·변경 2, 완료 매출 3,170,000원.
5회차 · 마케팅
“우리 말투” 비교와 광고 표현 점검이 핵심. brand-voice.md 적용 전/후를 나란히 보여 주고, “치료·재생·주름 제거 보장” 같은 표현을 AI가 스스로 걸러 내게 하세요(규정은 수업 전 최신 확인).
6회차 · 홈페이지
아티팩트 공유 링크는 누구나 볼 수 있으니 개인 전화번호·고객 전후 사진을 넣지 않게 합니다. 예약 버튼은 네이버 예약 링크로 연결합니다. 인터넷 주소 연결은 부록 A로 안내.
7회차 · API와 웹훅
코딩 없는 회차입니다. “식당 주문서(API)”와 “초인종(웹훅)” 비유로 그림만 그립니다. 8~14회차의 기초라 서두르지 마세요. MCP는 “AI용 만능 콘센트, 커넥터는 서비스별 플러그”로 한 장만 소개하고, 연결 실습은 8회차로 넘깁니다.
8회차 · Slack
강사가 만든 실습 워크스페이스에 초대하는 방식이 가장 빠릅니다. Workflow Builder 사용 가능 플랜을 수업 전에 확인하세요. Slack 커넥터는 워크스페이스 관리자 승인이 있어야 연결되니 수업 전에 승인해 두고, 도구 권한은 “읽기 Always allow · 보내기 Needs approval”로 함께 맞춥니다. Pro 개인 계정에서 연결되는지는 강사가 미리 실기 확인(문서 상충).
9회차 · Jira
프로젝트 이름 “봄날 에스테틱 운영”, 키 BOM, 열 4개(접수→예약 확정→관리 완료→사후 연락 완료)를 그대로 맞추게 하세요. 이후 회차 예제가 이 이름을 씁니다. Atlassian 커넥터의 첫 연결은 사이트 관리자(수강생 본인 사이트면 본인)가 하게 하고, 허용 화면에서 사이트를 잘못 고르는 실수가 가장 많습니다.
10회차 · Slack↔Jira
Jira Free Automation은 사이트 전체 월 150 steps입니다. 수강생이 같은 사이트를 공유하면 한도가 금방 찹니다 → 각자 사이트 권장. “관리 완료 3일 뒤 사후 연락 이슈 자동 생성” 같은 지연·예약 규칙이 현재 플랜에서 되는지는 수업 전 확인하세요.
11회차 · AI 주간 보고
Jira에 이슈가 적으면 보고서가 빈약합니다. 수업 전 샘플 이슈 10~15개(예약·문의·클레임, 노쇼 포함)를 만들어 두게 하세요. Slack·Atlassian 커넥터를 둘 다 켰는지 먼저 확인하고, 프롬프트 인젝션(이슈·메시지 속 숨은 지시) 이야기로 “쓰기는 승인 후”를 다시 강조합니다.
12회차 · LINE 자동응답
일본어 계정 화면이 섞여 나옵니다. 메뉴명을 일본어·한국어로 병기한 화면 캡처를 미리 준비하세요. 「予約できますか」처럼 예약 문의는 자동응답이 네이버 예약 링크로 안내만 하고 확정하지 않게 합니다.
13회차 · Make 상담봇
API 키를 화면 공유 중에 노출하지 않도록 주의. Make 무료 credits가 테스트 반복으로 빨리 줄어듭니다.
14회차 · 봇 서버 & 졸업
배포는 앞 45분, 발표는 뒤 45분으로 시간을 엄격히 나눕니다. 배포에 실패해도 13회차 Make 봇으로 발표할 수 있게 하세요.
부록 F · Slack·Jira MCP 연결
8·9회차를 마친 수강생 대상 보충(약 75분). 커넥터 화면 이름이 자주 바뀌니 강사 계정으로 미리 연결해 보고 캡처해 두세요. Claude Code 사용자는 Atlassian 주소로 https://mcp.atlassian.com/v2/mcp를 쓰게 하고, 옛 자료의 …/v1/sse(2026-06-30 종료)는 쓰지 않게 합니다. ⚠️ 표시 사실은 수업 전 확인.

4. 수업 전 강사 준비

계정 · 환경

  • 강사용 Claude Pro 계정 (데모 전용, 개인 대화 기록 없는 것)
  • 실습용 Slack 워크스페이스 + 채널 #공지 #예약 #문의 #스탠드업 #cs-escalation
  • 강사용 Jira 사이트 + 프로젝트 “봄날 에스테틱 운영”(BOM)
  • 테스트용 LINE 공식계정 + 친구 추가한 테스트 폰(또는 두 번째 LINE 계정)
  • Make 계정 + 13회차 완성본 시나리오
  • Cloudflare 계정 + examples/messenger-bot/ 배포 확인
  • Anthropic Console 계정 + 사용 한도(Spend limit) 설정
  • MCP(8회차 전): 실습 Slack 워크스페이스에서 Claude 커넥터(MCP 연결) 관리자 승인 완료
  • MCP(8회차 전): Pro 개인 계정으로 Slack 커넥터 연결 실기 테스트 + 화면 캡처 (공식 문서 상충 — 수업 전 확인)
  • MCP(9회차 전): Atlassian 사이트 관리자 권한 확인, Administration › Rovo › Rovo MCP server에서 지원 도메인 허용 확인, BOM 이슈 읽기·만들기 테스트
  • MCP: 도구 권한(읽기 Always allow / 쓰기 Needs approval / 삭제 Blocked) 데모 설정, 부록 F 미리 보기

교실 · 자료

  • 빔프로젝터 해상도 확인, 브라우저 확대 125~150%
  • 강의 슬라이드를 미리 열고 N으로 노트 확인
  • dataset 파일 공유 링크(단톡방 등) 준비
  • 바뀐 화면·요금이 있는지 실제 서비스에서 확인
  • Wi-Fi 비밀번호와 휴대폰 문자 인증 가능 여부 안내
  • 문제 해결 카드(troubleshooting) 탭 열어 두기
강사 화면에서 API 키·Webhook URL·토큰이 보이면 그 즉시 폐기하고 재발급하세요. 녹화 영상에 남은 비밀값도 유출로 봅니다.

6. 강사 노트 보는 법

모든 슬라이드 아래에 강사 노트(시간 배분, 막히는 지점, 예상 질문)가 숨어 있습니다.

  1. 슬라이드에서 키보드 N을 누르거나 상단 바의 🎤 버튼을 누르면 노트가 보였다 숨었다 합니다.
  2. 주소 끝에 ?notes=1을 붙이면 처음부터 노트가 켜진 채로 열립니다. 예: lessons/01-ai-first-day.html?notes=1
  3. 노트 켜짐 상태는 그 브라우저에 기억됩니다. 수강생에게 화면을 넘기기 전 꼭 끄세요.
노트북은 노트를 켠 창, 빔프로젝터는 노트를 끈 창(다른 브라우저 또는 시크릿 창)으로 두 개를 띄우면 편합니다.

7. PDF로 인쇄하기

  1. 크롬에서 강의 슬라이드를 엽니다. (강사용 PDF가 필요하면 먼저 N으로 노트를 켭니다)
  2. Ctrl+P (맥은 ⌘+P)
  3. 대상: PDF로 저장 · 레이아웃: 가로 · 더보기 → 배경 그래픽 체크
  4. 저장 → 슬라이드 1장이 PDF 1쪽으로 나옵니다.

이 페이지 같은 자료 페이지도 같은 방법으로 인쇄됩니다(세로 권장).

8. 평가

회차별 결과물 포트폴리오

수강생은 매 회차 결과물 1개를 하나의 폴더(또는 Claude 프로젝트, Slack 채널 등)에 모읍니다. 14개 중 10개 이상 제출 시 수료를 권장합니다. 결과물 목록은 시간표의 “결과물” 열과 같습니다.

졸업 발표 루브릭 (14회차, 1인 5분)

항목3점 (훌륭)2점 (좋음)1점 (보완)
