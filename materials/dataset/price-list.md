## 상품

| 상품 | 가격 | 설명 |
|---|---:|---|
| 꽃다발 S | 35,000원 | 한 손에 쏙, 생일·감사 선물 |
| 꽃다발 M | 55,000원 | 가장 인기 있는 크기, 기념일·프러포즈 |
| 꽃다발 L | 85,000원 | 풍성한 크기, 졸업·축하 행사 |
| 꽃바구니 | 70,000원~ | 병문안·부모님 선물 (예산에 맞춰 제작) |
| 개업 화환 | 120,000원~ | 리본 문구 무료 |
| 정기구독 (월 4회) | 월 120,000원 | 매주 1회 계절 꽃 배송 |

## 배송

| 항목 | 내용 |
|---|---|
| 당일 배송 | 오후 3시까지 주문 시 서울 지역 당일 배송 |
| 배송비 | 5,000원 |
| 무료 배송 지역 | 마포구, 서대문구 |
| 서울 외 지역 | 담당자 확인 후 안내 |

## 결제 · 환불

- 결제: 카드, 계좌이체, 네이버 스마트스토어
- 제작 시작 전: 전액 환불
- 제작 시작 후: 환불 불가 (생화 특성)
- 배송 중 파손: 사진 확인 후 재제작

## 무료 서비스

- 메시지 카드
- 리본 문구 (화환)

## orders-sample.csv 읽는 법

- `금액` = 단가 × 수량 + 배송비(5,000원). 매장 수령, 마포구·서대문구는 배송비 0원.
- 정기구독은 월 120,000원에 배송비가 포함된 것으로 계산했습니다(실습용 가정).
- `상태` 값은 Jira 보드 열과 같습니다: 접수 → 제작 중 → 배송 중 → 완료 (그 외 취소, 환불).
