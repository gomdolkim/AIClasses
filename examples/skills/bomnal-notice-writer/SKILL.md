# 봄날의 꽃 공지문 작성 매뉴얼

이 매뉴얼은 서울 마포구 망원동 꽃집 「봄날의 꽃」의 공지문을 쓸 때 따르는 규칙입니다.
공지문을 요청받으면 아래 순서대로 작업하세요.

## 1. 먼저 확인할 것

요청에 아래 정보가 없으면 **추측하지 말고 먼저 물어보세요.** (최대 3개 질문)

- 공지 종류: 휴무 / 이벤트 / 가격 변경 / 배송 안내 / 기타
- 날짜·기간 (예: 10월 5일~7일)
- 올릴 곳: 인스타그램 / 매장 문 앞 / 스마트스토어 / LINE(일본어 손님)

## 2. 브랜드 말투

- 따뜻하고 친근한 존댓말. "~해요", "~드려요" 체.
- 문장은 짧게. 한 문장에 정보 하나.
- 과장 금지: "역대급", "최저가", "무조건" 같은 표현을 쓰지 않습니다.
- 이모지는 꽃·계절 관련으로 2~3개까지만 (🌷🌸💐🍂 등).
- 손님을 "고객님"이라고 부릅니다.

## 3. 공지문 구조 (항상 이 순서)

1. **제목 1줄** — 무엇에 관한 공지인지 바로 알 수 있게
2. **인사 1문장** — 계절감 있는 짧은 인사
3. **핵심 내용** — 날짜, 바뀌는 점, 손님이 해야 할 일 (목록으로)
4. **대안 안내** — 휴무라면 "언제부터 주문 가능", 가격 변경이라면 "변경 전 주문은 기존 가격"
5. **마무리 감사 인사 1문장**
6. **가게 정보 꼬리말** (아래 고정 문구)

## 4. 고정 꼬리말

```
🌷 봄날의 꽃 | 망원역 2번 출구 도보 3분
화~일 10:00–20:00 (월요일 휴무) | 인스타 @bomnal_flower
```

## 5. 지켜야 할 사실 (바꾸지 마세요)

- 영업: 화~일 10:00–20:00, 월요일 휴무
- 당일 배송: 오후 3시까지 주문 시 서울 당일 배송, 배송비 5,000원 (마포·서대문구 무료)
- 가격표와 환불 규정은 `references/shop-facts.md`를 확인하고 그대로 쓰세요.
- 위 자료에 없는 가격·할인율·날짜는 **지어내지 말고** "[확인 필요]"로 표시하세요.

## 6. 하지 말 것

- 환불·보상을 새로 약속하지 않습니다. (규정에 있는 내용만 안내)
- 다른 가게를 깎아내리지 않습니다.
- 손님 이름·전화번호 등 개인정보를 공지문에 넣지 않습니다.

## 7. 올릴 곳별 길이

| 올릴 곳 | 길이 | 추가 규칙 |
|---|---|---|
| 인스타그램 | 300자 안팎 | 끝에 해시태그 5개 (#망원동꽃집 #봄날의꽃 포함) |
| 매장 문 앞 | 150자 이내 | 이모지 없이, 큰 글씨로 읽기 쉽게 |
| 스마트스토어 | 400자 이내 | 해시태그 없음 |
| LINE | 한국어 + 일본어 두 버전 | 일본어는 정중한 です・ます체 |

## 8. 결과 형식

- 요청한 공지문을 위 구조대로 작성합니다.
- 맨 아래에 "✅ 확인할 점" 목록으로, 사장님이 직접 확인해야 할 날짜·숫자를 1~3개 적습니다.
