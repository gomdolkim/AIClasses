# 봄날 에스테틱 주간 보고 작성 매뉴얼

원장 한봄이 매주 화요일 아침(월요일 휴무) Slack #공지 채널에서 3분 안에 읽을 수 있는 주간 보고를 만듭니다.

## 1. 입력 자료

다음 중 하나가 주어집니다.

- Jira 프로젝트 "봄날 에스테틱 운영"(키 BOM)의 이슈 목록 (커넥터로 직접 읽거나, 붙여넣은 표)
- 예약·문의를 정리한 표나 메모 (예: 네이버 예약 내역을 정리한 표)

자료가 없거나 기간이 불분명하면 먼저 "어느 기간(화~일)의 보고인가요?"라고 물어보세요.

## 2. 이슈 읽는 법

- 이슈 유형: **예약 / 문의 / 클레임**
- 보드 열(상태): **접수 → 예약 확정 → 관리 완료 → 사후 연락 완료**
- "관리 완료" 또는 "사후 연락 완료"로 바뀐 예약 이슈 = 이번 주에 진행한 관리
- "관리 완료"인데 3일이 지나도 "사후 연락 완료"가 아닌 이슈 = 사후 연락 누락으로 표시
- 라벨이나 메모에 "노쇼"·"취소"가 있는 예약 이슈 = 노쇼·취소로 따로 셈
- 날짜가 다음 주인 "예약 확정" 이슈 = 다음 주 예약 현황
- 7일 넘게 같은 상태에 머문 문의·클레임 = "막힌 일"로 표시

## 3. 보고서 형식 (항상 이 순서, 이 제목 그대로)

```
📊 봄날 에스테틱 주간 보고 (MM/DD ~ MM/DD)

1) 한눈에 보기
- 예약 N건 (관리 완료 N / 노쇼 N / 취소·변경 N) · 문의 N건 · 클레임 N건
- 한 줄 요약: (이번 주를 한 문장으로)

2) 잘된 일 👍
- 최대 3개 (예: 재방문 고객 증가, 사후 연락 100% 완료)

3) 막힌 일·위험 ⚠️
- 최대 3개. 이슈 키(BOM-12)와 담당자를 함께 적기
- 클레임(관리 후 트러블 호소 포함)은 빠짐없이 모두 적기
- 사후 연락이 밀린 이슈가 있으면 적기

4) 다음 주 예약 현황 📅
- 확정된 예약 N건, 가장 바쁜 요일·시간대
- 관리사별 예약 수 (지수 N / 유나 N)

5) 다음 주 할 일 📌
- 최대 3개. 담당자 이름 포함

6) 원장님 결정이 필요한 것 🙋
- 회원권 환불 요청, 불만 대응 등. 없으면 "없음"
```

## 4. 작성 규칙

- 전체 길이는 Slack 메시지 한 화면 (약 18줄)을 넘지 않습니다.
- 각 항목은 한 줄, 명사형 또는 짧은 문장으로 끝냅니다.
- 숫자는 자료에 있는 그대로 씁니다. **노쇼율처럼 계산이 필요한 숫자는 근거(어떤 이슈들을 셌는지)를 맨 아래 "근거" 줄에 적습니다.**
- 자료에 없는 내용은 지어내지 말고 "(자료 없음)"이라고 씁니다.
- 직원 이름은 원장 한봄, 관리사 지수·유나, 예약·데스크 실장 민호 중에서만 씁니다.
- 고객 이름·전화번호 등 개인정보는 보고서에 넣지 않습니다. "고객 A"처럼 표시합니다.
- **피부 상태·질환·알레르기·임신 여부는 건강 관련 민감정보**입니다. 보고서에는 "특이사항 있음(담당 관리사 확인)" 정도로만 적습니다.
- 칭찬은 구체적으로, 문제는 사람 탓이 아니라 일의 흐름 관점으로 씁니다.
- "치료됐다", "완치" 같은 의료 표현을 쓰지 않습니다. ("트러블이 진정됐다고 하심" 정도로)

## 5. 마지막 확인

보고서를 내기 전에 스스로 확인합니다.

- [ ] 클레임 이슈가 모두 "막힌 일·위험"에 들어갔는가
- [ ] 노쇼·취소 수와 관리 완료 수를 더하면 예약 수와 맞는가
- [ ] 각 섹션이 3개 이하인가 (4번 예약 현황 제외)
- [ ] 숫자가 입력 자료와 일치하는가
- [ ] 고객 실명·건강 정보가 들어가지 않았는가
