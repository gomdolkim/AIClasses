# Make로 상담 폼(구글 폼) → Jira 이슈 + Slack 알림 — 단계별 가이드 (10회차 보너스)

> 대상: 10회차까지 마친 분 (Slack 워크스페이스, Jira 프로젝트 `BOM` 있음)
> 걸리는 시간: 약 40분 · 비용: 무료 플랜으로 가능
> 요금·한도·메뉴 이름은 **2026-10 기준**이며 바뀔 수 있습니다. 화면이 다르면 강사에게 알려 주세요.

## 완성하면 이렇게 움직입니다

```text
손님이 홈페이지의 "상담·문의" 구글 폼 작성
  → [1] Google Forms · Watch Responses   (새 응답 확인)
  → [2] Jira · Create an Issue           (BOM 프로젝트에 예약/문의/클레임 이슈)
  → [3] Slack · Create a Message         (#문의 채널에 "새 폼 접수 BOM-○○" 알림)
```

자동화 사다리로 보면 **L3(연결 도구)** 입니다. Slack·Jira **밖의** 앱(구글 폼)을 잇기 때문에 Jira Automation이 아니라 Make를 씁니다.

> 📅 **시간 예약 자체는 계속 네이버 예약으로 받습니다.** 이 폼은 "네이버로 해결이 안 되는" 요청을 모으는 곳입니다. 예: 2인 동시 관리, 일본어 상담 희망, 회원권 문의, 관리 후 불편 사항.

## 준비물 체크

| 준비물 | 어디서 | 메모 |
|---|---|---|
| Google 계정 | 구글 폼을 만들 계정 | 샵 대표 메일 권장 |
| Make 계정 | make.com | 무료 플랜: 월 1,000 credits, 활성 시나리오 2개 (2026-10 기준) |
| Slack 워크스페이스 | 8회차 | `#문의` 채널, 내가 관리자 |
| Jira 프로젝트 `BOM` | 9회차 | 이슈 유형 `예약`, `문의`, `클레임`이 **정확히** 있어야 함 |

> ⚠️ Make 무료 플랜의 활성 시나리오는 2개뿐입니다. 13회차 LINE 상담봇용으로 **1개는 남겨 두세요.**

## 비용 감 잡기 (2026-10 기준)

- Make는 모듈이 한 번 실행될 때마다 보통 **1 credit**을 씁니다.
- 폼 응답 1건 처리 ≈ **3 credits** (확인 1 + Jira 1 + Slack 1).
- **새 응답이 없어도 확인할 때마다 1 credit**이 나갑니다. 그래서 "얼마나 자주 확인할지"가 제일 중요합니다.

| 확인 주기 | 한 달 확인 횟수 | 확인만으로 쓰는 credits |
|---|---|---|
| 15분마다, 24시간 | 4 × 24 × 30 = 2,880 | 2,880 → **무료 한도 초과** ❌ |
| 1시간마다, 24시간 | 24 × 30 = 720 | 720 (응답 처리에 280만 남음) |
| 1시간마다, 영업시간(11~21시)·화~일만 | 약 11 × 26 = 286 | 286 → 응답 약 200건 처리 가능 ✅ |

> 이 가이드는 마지막 줄(영업시간에만 1시간마다)을 추천합니다. 일요일은 18시에 마감하지만 설정을 단순하게 하려고 화~일 같은 시간대로 잡았습니다. 계산은 단순화한 예시이니 첫 주에 Make의 사용량(Credits) 화면으로 꼭 확인하세요.

## 1단계 · 구글 폼 만들기 (10분)

1. 크롬에서 `forms.google.com` → **빈 양식(Blank)**
2. 제목: `봄날 에스테틱 상담·문의`
3. 폼 맨 위 설명에 적기: **"시간 예약은 네이버 예약에서 해 주세요(링크). 이 폼은 상담·문의용입니다."**
4. 질문을 아래처럼 만듭니다. **문의 유형의 보기 글자는 Jira 이슈 유형 이름과 똑같이** 적어야 합니다.

| 질문 | 질문 유형 | 필수 | 메모 |
|---|---|---|---|
| 문의 유형 | 객관식: `예약` / `문의` / `클레임` | ✅ | Jira 유형과 글자 하나까지 같게. 설명: "예약=네이버로 어려운 예약 상담, 클레임=관리 후 불편 사항" |
| 성함 (성만 적어도 됩니다) | 단답형 | ✅ | |
| 연락받을 방법 | 객관식: 인스타 DM / LINE / 전화 | ✅ | |
| 희망 날짜 | 날짜 | | 예약 상담일 때 희망 관리일 |
| 관심 관리 | 객관식: 수분 진정 / 여드름·트러블 케어 / 리프팅 탄력 / 등 관리 / 첫 방문 체험 / 잘 모르겠어요 | | |
| 내용 | 장문형 | ✅ | |

5. 내용 질문 설명에 이렇게 적어 둡니다: **"피부 질환·알레르기·임신 여부 같은 건강 정보와 카드번호는 적지 마세요. 상담이 필요하면 원장이 직접 연락드립니다."**
6. 오른쪽 위 **보내기(Send)** → 링크 복사 → 6회차 홈페이지에 "상담·문의하기" 버튼으로 연결 (선택. 네이버 예약 버튼과 헷갈리지 않게 이름을 다르게)
7. 테스트용으로 응답을 1개 직접 제출해 둡니다. (Make가 질문 칸을 알아보는 데 필요)

> 🔒 이 폼 응답은 Jira와 Slack에 그대로 복사됩니다. 전화번호를 받지 않는 것이 가장 안전합니다. 꼭 받아야 한다면 Jira 설명에는 넣지 마세요(3단계 참고). 피부 상태·질환은 개인정보보호법상 건강 관련 민감정보에 해당할 수 있으니 폼으로 모으지 말고, 내방 상담 때 고객 카드에만 기록합니다.

## 2단계 · Make 가입과 새 시나리오 (3분)

1. `make.com` → **Get started free** → Google 계정으로 가입
2. 왼쪽 메뉴 **Scenarios(시나리오)** → **Create a new scenario(새 시나리오 만들기)**
3. 가운데 큰 **+** 버튼이 보이면 준비 완료

## 3단계 · 모듈 연결하기 (20분)

### [1] Google Forms · Watch Responses (새 응답 확인)

- 가운데 **+** → `Google Forms` 검색 → **Watch Responses**
- Connection: **Add** → Google 로그인 → 허용
- Form: 1단계에서 만든 `봄날 에스테틱 상담·문의` 선택
- Limit: `10`
- 처음 시작 위치를 물으면 **From now on(지금부터)** 선택 (테스트 응답을 쓰려면 "모든 응답"으로 한 번 실행 후 바꿔도 됨)

> 모듈 이름이 다르거나 Google Forms 앱이 안 보이면, 폼의 **응답 → 스프레드시트에 연결** 후 `Google Sheets · Watch New Rows`로 대신해도 됩니다. 이후 단계는 같습니다.

### [2] Jira · Create an Issue (이슈 만들기)

- [1] 오른쪽의 반원 **+** → `Jira` 검색 → **Create an Issue**
- Connection: **Add** →
  - 화면이 Atlassian 로그인 방식이면: 9회차 사이트(`bomnal.atlassian.net`)로 로그인 → 허용
  - 화면이 **API 토큰** 방식이면: 아래 "API 토큰 만들기"를 먼저 하고 Service URL `https://bomnal.atlassian.net`, 이메일, API 토큰 입력
- Project: `봄날 에스테틱 운영 (BOM)`
- Issue type: [1]의 **문의 유형** 답을 연결 (`예약`/`문의`/`클레임`)
  - 드롭다운만 보이면: [1] 다음에 **Router**를 넣어 세 갈래로 나누고, 각 갈래 Jira 모듈에서 유형을 직접 고르세요. (Router·필터는 credit을 쓰지 않습니다)
- Summary:

```text
[폼][{{1.문의 유형}}] {{1.관심 관리}} · {{1.희망 날짜}} · {{1.성함}}님
```

- Description:

```text
구글 폼 접수
- 연락 방법: {{1.연락받을 방법}}
- 관심 관리: {{1.관심 관리}}
- 희망 날짜: {{1.희망 날짜}}
- 내용: {{1.내용}}
처리 후 손님이 고른 연락 방법으로 결과를 알려 주세요.
예약이 정해지면 네이버 예약 링크를 보내 드리고, 건강 관련 내용은 이 이슈에 적지 말고 고객 카드에만 기록하세요.
```

- Due date(기한): 유형이 예약이면 `{{1.희망 날짜}}` 연결 (비어 있으면 그대로 둠)

> `{{1.○○}}`는 직접 타이핑하는 것이 아니라, 입력칸을 클릭하면 뜨는 목록에서 [1] 모듈의 항목을 **클릭해서** 넣는 것입니다.

#### API 토큰 만들기 (API 토큰 방식일 때만)

1. `id.atlassian.com/manage-profile/security/api-tokens` → **API 토큰 만들기(Create API token)**
2. 이름: `make-form`, 만료일: 가능한 짧게(예: 3개월)
3. 나온 토큰을 **바로** Make 입력칸에 붙여넣기 → 창 닫기

> 🔑 **API 토큰 = 우리 샵 열쇠(7회차).** 메모장·카톡·Slack에 저장하지 마세요. 새 나간 것 같으면 같은 화면에서 **취소(Revoke)** 후 새로 만듭니다.

### [3] Slack · Create a Message (알림 보내기)

- [2] 오른쪽 **+** → `Slack` 검색 → **Create a Message**
- Connection: 봄날 에스테틱 워크스페이스 로그인 → 허용
- Channel: `#문의` (봇을 채널에 초대해야 할 수 있음: 채널에서 `/invite @Make`)
  - (선택) Router를 썼다면 `예약` 갈래만 `#예약` 채널로 보내도 됩니다.
- Text:

```text
📝 새 폼 접수 · {{1.문의 유형}}
• 이슈: {{2.key}}
• 손님: {{1.성함}}님 ({{1.연락받을 방법}})
• 관심 관리: {{1.관심 관리}} / 희망 날짜: {{1.희망 날짜}}
👉 Jira에서 담당자를 정하고 스레드로 진행 상황을 남겨 주세요.
```

> 10회차에 만든 **Incoming Webhook URL**을 쓰고 싶다면 Slack 모듈 대신 **HTTP · Make a request** (POST, JSON 본문 `{"text": "..."}`)도 됩니다. Webhook URL은 비밀번호처럼 다루세요.

## 4단계 · 테스트하고 켜기 (7분)

1. 아래쪽 **Run once(한 번 실행)** 클릭
2. 다른 창에서 폼을 하나 제출 (유형: `문의`, 내용: "회원권 남은 횟수를 가족이 써도 되나요?")
3. 각 모듈 위에 초록 동그라미와 숫자가 뜨면 성공. 말풍선을 눌러 들어간 값 확인
4. Jira 보드 "접수" 칸, Slack `#문의`에 새 글이 생겼는지 확인
5. 유형 `클레임`으로 한 번 더 제출 (내용: "관리 받은 다음 날 볼이 조금 붉어요") → 10회차 **규칙 ②**도 같이 돌아서 `#cs-escalation` 알림과 원장 할당이 되는지 확인
6. 왼쪽 아래 **시계 아이콘(Scheduling)**:
   - Run scenario: **At regular intervals(정해진 간격)** → `60` 분
   - 고급 설정(Advanced scheduling)에서 요일 **화~일**, 시간 **11:00~21:00** 으로 제한 (월요일 휴무. 메뉴가 다르면 수업 전 확인)
7. 시나리오 이름 `폼 → Jira + Slack` → 저장 → 스위치를 **ON**

> Make가 만든 클레임 이슈에도 Jira Automation 규칙 ②가 돌기 때문에 **Jira steps도 같이 씁니다.** (10회차 계산표에 더하기)

> 🩺 클레임(관리 후 트러블 호소)은 **원장이 직접** 연락합니다. 답변에서 진단·치료 표현은 쓰지 않고, 필요하면 피부과 진료를 권합니다. 환불·보상은 통화 전에 약속하지 않습니다.

## 자주 겪는 문제

| 이럴 때 | 이렇게 |
|---|---|
| [1]에서 질문 항목이 안 보인다 | 폼에 테스트 응답을 1개 넣고 [1]을 "Run this module only"로 한 번 실행 |
| Jira `issue type` 오류 | 폼 보기 글자와 Jira 유형 이름(`예약`/`문의`/`클레임`)이 정확히 같은지, 띄어쓰기까지 확인 |
| Jira `401` / 권한 오류 | 연결에 쓴 계정이 BOM 프로젝트 멤버인지, API 토큰을 끝까지 복사했는지 확인 |
| Slack `not_in_channel` | 채널에서 `/invite @Make`로 앱 초대 |
| 날짜가 이상하게 들어간다 | Due date에 `{{formatDate(1.희망 날짜; "YYYY-MM-DD")}}` 사용 |
| 손님이 폼으로 시간 예약을 확정하려 한다 | 폼 설명과 답변에서 "예약 확정은 네이버 예약에서"를 안내. 폼 접수 = 상담 요청일 뿐 |
| 응답이 와도 한참 뒤에 알림이 온다 | 1시간 간격이라 정상. 더 빠르게 하면 credits가 빨리 닳음 (비용표 참고) |
| 월말에 시나리오가 멈췄다 | Make credits 소진 → 사용량 확인, 확인 주기 늘리기 또는 Core 플랜($9~) 검토 |

## 보안·개인정보 정리

- 폼에서 **카드번호·비밀번호는 받지 않습니다.** 전화번호도 가능하면 받지 않습니다.
- **피부 질환·알레르기·임신 여부 등 건강 정보는 폼·Jira·Slack 어디에도 받지 않습니다.** 내방 상담 때 고객 카드에만 기록합니다.
- Jira·Slack에는 **성이나 이니셜만** 적는 9회차 규칙을 그대로 지킵니다.
- Atlassian API 토큰, Slack Webhook URL은 **열쇠**입니다. 단톡방·스크린샷·Claude 채팅에 붙여넣지 않습니다.
- 수업이 끝나고 안 쓰는 시나리오는 **OFF**로, 안 쓰는 API 토큰은 **취소(Revoke)** 합니다.
